# DQ9-sus 축 라벨 오류 규명 + 조제간 재현성 정량

**작업일** 2026-08-11 · **데이터** `Ratio/Baseline260808/` (Google Drive: `ACF_PEST_DB/Ratio/Baseline260808`)

두 가지를 확정했다. (1) `DQ9-sus`는 혼합 실수가 아니라 **파일명 두 축이 서로 바뀐** 것이다.
(2) 이를 재라벨하니 같은 조건의 독립 조제 12쌍이 생겼고, 이 프로젝트에 없던
**혼합물 조제간 재현성**을 처음으로 정량했다.

## 1. 결론

### 1-1. `DQ9-sus`의 두 축은 서로 바뀌어 있다 (확정)

```
파일명  DQ9-TB{a}-TH{b}_corrected.csv   →   실제 조건  DQ 9 µM,  TBZ = {b},  THI = {a}
```

재라벨 사본: **`Ratio/Baseline260808/DQ9-sus-relabeled/`** (12개 + `RELABEL_MAP.csv`).
원본 `DQ9-sus/`는 그대로 두었고 체크섬 12/12 일치. `DQ9/` (16맵)는 정상이며 기준으로 쓴다.

독립적인 두 갈래가 일치한다.

- **데이터** — 2원 회귀 `log2(추정농도) = c0 + a·log2(TB라벨) + b·log2(TH라벨)` (95% CI)

  | | TBZ~TB라벨 | TBZ~TH라벨 | THI~TB라벨 | THI~TH라벨 |
  |---|---|---|---|---|
  | `DQ9` (정상 대조군) | **+1.00**±0.53 | −0.09±0.53 | +0.20±0.29 | **+1.00**±0.29 |
  | `DQ9-sus` | −0.06±0.75 | **+1.05**±0.55 | **+0.61**±0.59 | +0.39±0.43 |

- **실험 기록** (사용자 증언) — THI를 세로축에 **3칸만** 찍었고, 측정 중 이상을 눈치채
  마지막 줄을 일부러 안 했다(그래서 16맵이 아니라 12맵). 파일명에서 3수준인 필드는
  `TB`(18/36/72) 하나뿐 → **TB 자리 = 세로축 = THI**.

세 가설 정면 비교 (4개 계수 중 기각 개수 / 고정계수 잔차분산 / 재라벨 후 DQ9와 평균거리):

| 가설 | 기각 | 잔차분산 | 평균거리 |
|---|---|---|---|
| ① 파일명 그대로 | **4/4** | 3.90 | 0.407 |
| **② 두 축 서로 바뀜** | **0/4** | **1.36** | **0.198** |
| ③ TB축 死 + THI는 TH따름 | 2/4 | 1.78 | 0.245 |

재라벨 전후 산점도: r **−0.151 → +0.792**, RMSE **0.267 → 0.130**.

### 1-2. 조제간 재현성 (n = 12쌍, 추가 측정 0회)

실제 프로토콜: 혼합물을 종이에 떨어뜨려 **완전 건조** → 그 위에 잉크 용액 **2 µL 액적** →
건조 → 10×10 맵. 산포 단위는 "시료 액적"이 아니라 **조제 1회분 전체**다.
잉크는 같은 stock·같은 부피 = **통제 변수**.

| 층 | 내용 | 조제간 CV |
|---|---|---|
| 1 | 잉크 리포터 2137 cm⁻¹ — 통제 변수 | **7.7%** |
| 2 | 농약총량/잉크 = 마른 스팟 → 잉크 **회수율** | **24.5%** |
| 3 | 조성 분율 | DQ **25.0%** · TBZ **21.9%** · THI **20.0%** |

- 조성 분율 RMSE **0.130**, 계통 편의 −0.001(없음), 95% 일치한계 ±0.26
- 성분별 조제간 SD: DQ 0.083 · TBZ 0.082 · THI 0.100
- 스펙트럼 cos 중앙값 0.979, 로그비 S/N: THI/DQ **1.55** · THI/TBZ 1.07 · TBZ/DQ **0.80**

**해석**: 잉크 증착·기재 균일성은 잘 통제되고 있다. 흔들리는 곳은 **건조된 농약이 잉크에
재용해되어 올라오는 단계**이며, 총량만이 아니라 **성분별로 비례하지 않게** 올라온다.
→ 리포터 CV는 1층만 증명한다. 조성 추정 재현성으로 전용하면 3배 이상 낙관적이 된다.

### 1-3. 단일 조제로는 2배 농도 차이를 못 가른다

판별력 `d′ = (한 칸 신호) / (조제간 잡음)`:

| 평균할 조제 수 | 1 | 2 | 3 | **4** | 6 | 8 |
|---|---|---|---|---|---|---|
| d′ | **1.13** | 1.60 | 1.95 | **2.25** | 2.75 | 3.19 |

최근접 조건 회수도 1순위 적중 2/12, 평균 순위 4.6/16.
→ "정밀 정량"이 아니라 **조성 + 대략 농도 구간** 판정이라는 프로젝트 전제의 정량적 근거.

## 2. 하지 말 것 (검증 완료된 막다른 길)

### 2-1. 픽셀 선택 튜닝 — 효과 없음

맵 안 100포인트가 실제로 이질적인 건 맞다(픽셀간 분율 SD 0.048~0.083, 맵에 따라 R² 0.18~0.96,
신호 동적범위 최대 14배). 그러나 **100점을 평균하면 픽셀 기여가 SD/√100 = 0.005~0.008**로
떨어져, 맵 대표값 불확도의 **0.5%**밖에 안 된다. 나머지 99.5%는 조제 공통성분이다.

18개 선택 규칙 실측 (목적함수 d′):

| 규칙 | d′ |
|---|---|
| 선택 없이 100점 전부 | **1.12** |
| 현재 방식 R² 상위 80% | **1.09** |
| R² 상위 50 / 30 / 10% | 1.05 / 0.92 / **0.87** |
| 총신호 상위 50% (최고) | **1.19** |

- **R² 필터를 조일수록 나빠진다.** 저장소의 R²/포화 픽셀 제외 로직(commit `d26ae97`)은
  명백한 쓰레기 픽셀 배제 목적으로는 유지해도 되나, **재현성 향상 효과는 없다.**
- 맵 단위 QC도 무효 — 쌍 거리와 중앙 R²(p=0.39)·픽셀SD(p=0.54)·동적범위(p=0.13) 모두 무상관.

### 2-2. 전 조건 3반복 측정 — 불필요

이미 12쌍이 있다. 4맵을 더 채워도 재현성 CI 폭이 0.068 → 0.056으로 좁아지는 정도다.
**액적/배치 분리 실험도 불필요** — 사용자 확인상 "찍을 때마다 거의 새 배치"라, 위 수치는
상한이 아니라 **실사용 재현성 그 자체**다.

### 2-3. `DQ9-sus`를 현 파일명 그대로 학습/검량에 투입 — 금지

라벨이 틀렸다. 반드시 재라벨본을 쓸 것.

## 3. 논문에 쓸 때

### 오차막대 표기 (중요)

| 표기 | DQ | TBZ | THI | |
|---|---|---|---|---|
| 픽셀 SEM (SD/√100) | 0.005 | 0.005 | 0.008 | **쓰지 말 것 — 진짜 오차의 1/15** |
| 픽셀 SD (n=100) | 0.048 | 0.054 | 0.083 | 맵 안 불균일성을 보여줄 때 |
| **조제 SD (n=12)** | **0.083** | **0.082** | **0.100** | **조성 결론에 붙일 오차막대** |

**n=100 픽셀은 독립 반복이 아니다 (pseudoreplication).** 같은 조건·다른 조제 12쌍 × 3성분
= 36 비교에서 n=100 t-검정 결과 **32/36이 p<0.05** — 정답은 '차이 없음'인데.
|Cohen d| 중앙값 1.4, 분포 겹침 중앙값 0.43 (21/36이 0.5 미만).

권장 서술: **"한 맵 안 100포인트의 SD가 0.05~0.08이고, 같은 조건을 다시 조제하면 중앙값
자체가 그만큼(0.08~0.10) 이동한다."** 두 숫자를 나란히 두면 pseudoreplication 시비 없이
산포의 실체를 전달한다.

### 본문 문장 초안

> 잉크 증착과 기재 균일성은 잘 통제된다 (2137 cm⁻¹ 밴드 조제간 CV 7.7%). 재현성의 지배적
> 원인은 건조된 분석물이 잉크 액적으로 회수되는 단계이며 (CV 24.5%), 그 결과 조성 추정의
> 조제간 CV는 20~25% (질량분율 RMSE 0.130, n = 12 조건)이다. 따라서 본 방법은 조성과
> 대략적 농도 구간을 판정하는 데 적합하며, 단일 조제로부터의 정밀 정량은 주장하지 않는다.

## 6. 남은 것

- **조건별 오차막대는 불가.** 조건당 조제가 2개(원본 1 + 재라벨 1)라 12조건 pooled 수치만
  나온다. 리뷰어가 특정 조건의 error bar를 요구하면 그 조건만 추가 조제가 필요하다.
- **재라벨 후에도 3개 조건**(`TB18-TH36`, `TB36-TH72`, `TB72-TH9` — 원본 파일명 기준)이
  DQ9와 거리 0.34~0.37로 남는다. 조제간 산포로 보이나 확인된 바는 아니다.
- **회수율 24.5%를 줄이려면** 잉크 쪽이 아니라 **농약 스팟 건조 조건과 잉크 접촉 시간**을
  건드려야 한다. 별개 최적화 과제.
- 패널 **a**의 "Analyte recovery"는 NNLS 계수 기준 (농약 3종 합)/(잉크 성분)이다. 논문에서
  recovery를 다른 정의로 쓴다면 "relative analyte signal" 등으로 용어를 바꿀 것.
