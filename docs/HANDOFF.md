브랜치 `claude/signal-pixel-dl-readout-6y2r2v` (`1e47f3f` 기반, 커밋 21개).

앞선 인계 문서(§1~§5 워크플로우·설계원칙·성능·파일·함정)는 **그대로 유효하다.**

## 1. 앞 인계 §6 — 세 항목 모두 닫힘

**증상이었던 것**: `260723_mixture(bg).csv`에서 `hide low-R²`가 1860/2100(89%)을
제외해 hit 0%. DL 조성은 TBZ 89%로 뒤집힘.

| 항목 | 결과 |
|---|---|
| 1. `hide low-R²` 확인 | **버그였다.** dlpx에서 R²를 MLP *확률*로 재구성해 거의 전 픽셀이 저-R²로 찍혔다. R²는 항상 NNLS 최소제곱 해로 계산하도록 수정. 이후 hit 픽셀 R² 통과율 100% (`2382b60`) |
| 2. `Load background…` | 추가됨 (`2382b60`). 다만 실측 검증 결과 **모델에 BLK 클래스가 있으면 불필요**했고, 최종 구조는 배경 판정을 NNLS가 담당 — 앞 문서의 방침("학습은 깨끗하게, 배경은 Real에서 판정")과 일치 |
| 3. 세 숫자 어긋남 | 정리됨. 픽셀 파이 = 맵 DL 조성이 자릿수까지 일치하고, 농도는 조성 비율로 분배해 **구조적으로** 일치 (`54c8f9e`, `ee79796`) |

**hit 0%의 확정 원인은 배경 판정이 아니라 R² 계산 버그였다.**

## 2. 최종 구조 (Real 탭)

| 담당 | 무엇을 |
|---|---|
| **NNLS** | 배경 / 물질 판정 |
| **MLP** | 조성 (픽셀별) |
| **MLP** | 농도 (픽셀별) — µM 헤드의 *총량*을 조성 비율로 분배 |

배경 판정 게이트는 **넷에서 하나로** 줄였다(모델 블랭크 채널 · min_frac 임계값 ·
실측 배경 점수 · R² 필터 → 우선순위 하나). 어느 규칙이 판정했는지 요약줄에
`background decided by: …`로 표시되고, 투표권을 잃은 위젯은 비활성화된다.

**R²는 필터가 아니라 경고**다(기본 꺼짐). 저-R² 픽셀은 코랄 ✕로 표시만 되고 조성에
그대로 들어간다. 레퍼런스가 그 픽셀을 잘 설명 못 한다는 뜻이지 조성이 틀렸다는
증거가 아니며, 그걸로 89%를 지운 것이 hit 0%의 정체였다.

## 3. 고친 것 (전부 실측 데이터로 검증)

검증 데이터는 `raw deleted` 직전 커밋 `52e1d33`에서 복원한 실측 맵을 썼다
(`git checkout 52e1d33 -- Reference`).

- **R² 버그** — 위 §1. `2382b60`
- **배경 판정 argmax 편향** `984ff54` — 모델은 확률을 물질 3채널로 쪼개고 BLK는
  1채널로 낸다. argmax는 물질 65%인 픽셀(.22/.22/.21/.35)을 배경으로 판정했고,
  **고르게 섞일수록 불리**했다. BLK 하나가 물질 합보다 클 때만 배경으로 변경.
- **DL 계산 이중화** `54c8f9e` — 요약줄이 모델을 두 번째로(맵 단위, 자체 픽셀 선택)
  돌려 파이와 다른 숫자를 말할 수 있었다. 이제 한 번만 돌린다.
- **`min substance %` 제거** `54c8f9e` — 맵 전체 평균 5% 미만 물질을 0으로 만들었다.
  미량 검출이 목적인 장비에서 트레이스를 지우는 동작. THI001(THI 0.5%)이
  "THI 없음"으로 보고되던 것이 이제 1%로 나온다.
- **농도 헤드 차원 버그** `afe40d9` — `learn background` + 농도를 함께 쓰면
  `tensor a (4) vs b (3)`로 학습이 죽었다. 블랭크는 농도가 없으므로 헤드가
  화합물만 담당하도록 수정. 기존 모델 호환 유지.
- **농도 헤드 학습 데이터** `0b5593f` — 맵당 평균 1줄(≈34개)로만 학습해놓고
  픽셀별로 적용하고 있었다. 조성 헤드와 같은 픽셀 행으로 학습하도록 변경.
- **조성 ↔ 농도 모순** `ee79796` — 두 헤드가 별개 신경망이라 "THI 61%"와
  "THI 0.146 µM"이 동시에 나올 수 있었다. µM 헤드에서 **총량만** 받아 조성 비율로
  나눈다. 이제 픽셀 단위로 두 readout이 같은 것을 말한다.
- **Benchmark TypeError** `b33dfb4` — `_opts()` 하나를 시그니처가 다른 세 함수에
  통째로 넘겼다(`benchmark_loo`는 `methods` 복수형, `include_blank` 없음).
  각 함수가 선언한 인자만 골라 전달.
- **스레드 크래시(0xC0000409)** `b33dfb4`, `58c59de` — `self._thread` 재대입으로
  살아있는 QThread의 마지막 참조가 사라져 Qt가 abort. **이 수정은 이미
  `claude/exit-code-c0000409-nrd2ng`(`18894ac`)에 있었으나 머지된 적이 없었다.**
  회수 후 Model/Recovery의 남은 손수 스레드도 `start_worker`로 전환.
- **`cm.get_cmap`** `58c59de` — matplotlib 3.9에서 제거된 API. 학습 후 삼각형
  그릴 때 AttributeError로 죽었다.
- **이식성 3건** `44faf61` — 하드코딩된 Windows 데이터 경로, matplotlib Qt 바인딩
  고정, Qt 플러그인 경로 복구. 역시 `exit-code` 브랜치에 방치돼 있던 것.
- **Recovery 적용 전용화** `efd5507` — 자체 학습 경로(method/epochs/seed 노브,
  `Save DL model`) 제거. 앞 문서 §2 "학습 노브는 학습부에만"에 맞춤.
- **Model 탭 `Load model…`** `58c59de` — 저장은 되는데 다시 열 수가 없어 매번
  재학습해야 했다. 열면 저장된 held-out 평가를 다시 그리고 MODEL_BUS로 발행한다.
- **export 스타일** `6f97340` — 전 그림 투명 배경 + 여백 최소화. Model 탭 삼각형
  4개 → 1개(Recovery는 요청대로 전체 유지, `2647a91`).
- **해석 그림 레이아웃** `e080272` — tight_layout이 스팬 축을 못 풀어 경고를 내고
  실제로 잘못 배치하고 있었다. 물질 1개일 때 두 패널이 겹쳐 그려지던 것도 수정.
- **calibration 응답 계수 노출** `76fd001` — µM을 좌우하는 `gA·K`가 화면에 없었다.
  물질별 상대 응답을 표시하고 50배 이상 벌어지면 경고.

## 4. 측정으로 **기각한** 가설 (다시 시도하지 말 것)

이 세션에서 세운 가설 6개 중 5개가 측정으로 탈락했다. 근거를 남긴다.

| 가설 | 결과 |
|---|---|
| Langmuir `gA`/`K` 분리 실패가 농도 오차의 원인 | **기각.** `C`는 곱 `gA·K`에만 의존하고, 포화 안 된 dilution series에서도 그 곱은 잘 복원된다(오차 0.99~1.05배). 실제 원인은 측정된 응답 기울기 비 자체 |
| 실측 배경을 스펙트럼에서 빼면 타 기판 맵을 읽을 수 있다 | **기각.** 오히려 악화(조성오차 0.03 → 0.17~0.21). 모델은 기판이 든 스펙트럼으로 학습됐고, ALS 베이스라인이 이미 낯선 기판을 흡수한다 |
| 블랭크 학습량(6%)이 부족해 배경 판정이 무너진다 | **기각.** 블랭크 비중 4.4%에서도 미학습 BLK-4 hit 0%, 배경 94% 맵 precision/recall 100% |
| BLK 레퍼런스가 잉크 포함 상태일 것 | **기각.** 피크 검출 기준을 맵별 상대값으로 잡은 내 측정 오류였다. 공통 절대 기준으로 재면 BLK 피크 3개(DQ/TBZ 16개), 최대 신호 420(THI 15310) — 맨 종이가 맞다 |
| `pixels/map`을 400으로 올리면 좋아진다 | **기각.** 밝은 40개는 TBZ 52:THI 43(참 50:50), 400개 전부는 TBZ 30:THI 59로 악화 |
| 심플렉스를 시뮬레이션으로 채우면 조성이 정확해진다 | **기각, 되돌림**(`8f6ab2d`). 아래 §5 참조 |

**진단 자체는 맞았다**: 조성 공간 내부가 비어 있다는 것은 앞 인계 문서 §7과 일치한다.
틀린 것은 **처방**이다. 문서의 처방(중간 조성 실측 추가)이 옳다.

## 5. 남은 핵심 문제 — TBZ 판별 불가

**TBZ가 전혀 없는 맵에서 모델이 TBZ를 반환한다.**

```
DQ1TH1  참 DQ 50 / TBZ  0 / THI 50  →  시뮬없음  2/30/68   시뮬3000  6/29/65
DQ3TH1  참 DQ 75 / TBZ  0 / THI 25  →  시뮬없음 44/47/ 9   시뮬3000 65/23/12
```

원인은 물리적이다. 측정된 응답 계수가 **DQ 1.2× · TBZ 1.0× · THI 29.7±12.6×** 이라,
등몰 1:1:1 용액이 표면에서 내는 신호는 대략 **DQ 4% : TBZ 3% : THI 93%** 다.
TBZ는 세 물질 중 응답이 가장 낮고 30배 강한 THI 밑에 깔려, 존재/부재를 가를 정보가
스펙트럼에 거의 없다. 그래서 모델은 사전분포를 채워 넣는다.

이것이 시뮬레이션을 되돌린 이유다. 시뮬레이션은 "TBZ가 안 보여도 33%라고 답해라"를
가르치는 셈이라 오탐을 **정당화**할 뿐이다. 1:1:1 맵에서 오차가 0.32→0.14로 준 것은
그 맵의 참값이 하필 Dirichlet(1,1,1)의 평균이라 생긴 착시였다.

부수적으로 **THI 응답의 상대 불확실성이 42%**(29.7±12.6)라, 보정 계수 자체가
이만큼 흔들리면 등몰을 33%로 정확히 되돌리는 데 원리적 한계가 있다.

## 6. 다음 작업

1. **중간 조성 실측 추가** — 앞 인계 §7 그대로. 500:300:200 같은 심플렉스 내부
   조성 몇 개. 이 세션의 측정도 같은 곳을 가리킨다.
2. **부재 성분 오탐률을 평가 지표에 추가** — 지금 어느 그림에도 안 잡힌다.
   AUC는 순위 지표라 이 편향을 보여주지 못한다(앞 문서 §3의 "검출은 동률"이
   그래서 나온 숫자다). fold-error 그림 프레임에 "성분 존재 vs 부재"로 나눠 얹으면
   그대로 검출 한계의 정량화가 된다.
3. **THI 응답 계수의 불확실성 축소** — ±12.6을 좁히지 않으면 보정 정확도의 상한이
   여기서 막힌다.
4. (선택) **Real 탭 "Intensity maps"** — dlpx에서 `A`가 모델 확률로 교체된 뒤라
   그 패널은 세기가 아니라 확률을 그린다. 제목이 오해를 부른다. 미수정.
5. (선택) **잉크 비분석물 클래스** — `is_blank()`가 인식하는 이름은
   `blk/blank/background/bg/none` 뿐이라, 잉크 레퍼런스를 `Reference/`에 넣으면
   농약처럼 조성 파이에 낀다. 비분석물(matrix) 클래스 지원 필요.

## 7. 이번 세션에서 배운 함정 (§5 "다시 만들지 말 것"에 추가)

- **모델 출력으로 적합도를 계산하지 말 것.** dlpx는 `A`를 확률로 교체하므로
  `A@templates`는 적합이 아니다. R²는 최소제곱 해(`A_ls`)로만 계산한다.
  픽셀 스펙트럼의 점선도 dlpx에서는 `model's reference mix`로 표기한다.
- **판정 게이트를 쌓지 말 것.** 배경 판정에 네 규칙이 AND로 묶여 있어 픽셀이
  사라져도 어느 게이트가 잘랐는지 알 수 없었다. 하나만 적용하고 무엇이 판정했는지
  결과에 기록한다(`UnmixResult.hit_rule`).
- **조용히 지우지 말 것.** `min substance %`와 R² 필터가 둘 다 데이터를 말없이
  삭제했다. 제외는 사용자가 켜는 옵션이어야 하고, 제외되지 않은 이상치는
  표시하되 남긴다.
- **한 점에서 성능을 재지 말 것.** 특히 그 점이 사전분포의 평균이면 무의미하다.
  부재 성분을 포함한 여러 조성에서 채점할 것.
- **다른 브랜치의 수정을 확인할 것.** 0xC0000409 크래시 수정이
  `claude/exit-code-c0000409-nrd2ng`에 있었지만 머지되지 않아, 같은 크래시를
  다시 만났다.
