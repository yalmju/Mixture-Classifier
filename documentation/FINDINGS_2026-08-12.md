## 2. 농도 — 6 µM 이상에서 준정량

```
성분당 6 µM 이상 (3 µM 제외)     2배 이내   3배 이내   중앙 배수오차   n
  DQ                               65%        92%        1.67×        60
  TBZ                              87%        98%        1.36×        61
  THI                              89%        98%        1.33×        61
  TBZ + THI                        88%        98%                    122
  세 성분 전체                     80%        96%                    182
```

3 µM 을 포함하면 DQ 55% · TBZ 79% · THI 87% 로 떨어진다. **떨어지는 것은 대부분
3 µM 이다** — DQ 19% · TBZ 50% · THI 81%.

> ### 2026-08-15 — 이 표의 출처와 "hybrid" 의 정체
>
> 위 숫자는 `conc38.py`(신호 비례 모델, held-out)다. **재현 확인됨** — 재실행이 어제와
> 일치한다. 2026-08-13 의 `conc_summary_hybrid_origin.csv` 에는 이보다 좋은 값
> (2배 이내 DQ 77 · TBZ 95 · THI 85%)이 있는데, **그걸 만든 스크립트가 저장소에 없다.**
> est 값의 크기로 보아 conc38 추정에 등온선(K) 보정을 덧씌운 별도 계산으로 보인다.
>
> 후보를 하나 배제했다: **MLP 농도 헤드는 그 출처가 아니다.** 같은 4-fold held-out 으로
> 재보니 (`conc_hybrid.py`) 2배 이내 DQ 56 · TBZ 56 · THI 22% 로 conc38 보다 나쁘고,
> THI 를 계통적으로 2–3배 과소평가한다. **µM 보고에 MLP 헤드를 쓰면 안 된다.**
> 보정 스크립트가 복원되기 전까지 **보고값은 이 conc38 표**다.

> ⚠ **"정량(quantitative)" 이라 쓰지 말 것.** 2배(50–200%)는 SANTE(70–120%, RSD ≤20%)
> 보다 4배 느슨하다. **준정량 스크리닝**이 정확한 표현이다. 다만 액적 산포가 1.2–1.5배라
> 단일 액적으로는 2배가 물리적 하한에 가깝다.

### LOD / LOQ — 6 µM 하한이 독립적으로 확인된다

단일성분 검량, `LOD = 3.3σ/기울기` · `LOQ = 10σ/기울기`.
σ 는 블랭크 7맵(BLK 4 + INK 3)의 맵간 SD, 기울기는 30 µM 이하 검량점 5개(원점 통과).

```
        LOD (µM)   LOQ (µM)      3 µM 에서 2배 이내 회수
DQ        1.56       4.72               19%
TBZ       1.74       5.26               50%
THI       0.37       1.13               81%
```

**LOQ 가 3 µM 에서의 성능과 정확히 맞아떨어진다.** DQ·TBZ 는 LOQ 가 4.7–5.3 µM 이라
3 µM 은 정량 범위 밖이고, THI 는 LOQ 1.13 µM 이라 3 µM 도 안에 든다 — 회수 성능이
19 / 50 / 81% 로 갈리는 것과 순서·크기가 모두 일치한다. 앞서 회수율만 보고 경험적으로
잡은 **6 µM 보고 하한이 세 성분 LOQ 를 모두 넘기는 첫 격자 수준**이다.

### 혼합 LOD — 감도는 별로 안 떨어진다

64조건 격자 65맵에서 **자기 농도에 대한 B 의 기울기**를 직접 재고, 같은 블랭크 σ 를 쓴다.

```
        혼합 기울기   단일 대비   혼합 LOD (µM)   혼합 LOQ (µM)
DQ          830        82%           1.90            5.77
TBZ        1252       118%           1.47            4.46
THI        1776        76%           0.49            1.49
```

DQ 1.90 µM 은 문서의 혼합 LOD 2.90 µM 과 같은 크기다. **검출 감도 자체는 혼합물에서
크게 안 떨어진다**(76–118%).

> ⚠ TBZ 가 118% 로 1을 넘는 건 비교 구간이 달라서다 — 단일 기울기는 0.1–10 µM,
> 혼합 기울기는 3–24 µM 에서 왔다. 정밀한 비교로 읽지 말 것.

**그런데 B 가 자기 농도를 잘 안 따라간다.** 혼합물에서 B 대 자기 농도의 R² 는
DQ 0.47 · TBZ 0.64 · THI 0.67 이다. 잔차 σ 로 LOD 를 다시 계산하면 16–22 µM 로 작업구간
전체를 덮어버린다.

**이것이 판독 경로가 raw B 가 아닌 이유다.** 단일 맵의 NNLS 계수 하나로는 혼합물에서
농도를 못 읽는다 — 그래서 조성은 학습 모델이, 농도는 응답계수 + 게인이 담당한다.
`lod_mixture.csv` 에 두 σ 기준을 다 넣어뒀으니 **어느 쪽인지 밝히고 인용할 것.**

R² 0.47–0.67 이 낮은지 높은지는 무엇과 겨루느냐로 정해진다. 같은 65맵에서 판독 방식만
바꿔 보면:

```
                 B vs C 선형   log B vs log C   조성비 vs 참조성   게인 보정 후
DQ                  0.471          0.033           0.486           0.608
TBZ                 0.639          0.709           0.618           0.788
THI                 0.666          0.727           0.740           0.821
맵별 게인(총B/총C) 산포:  5–95 백분위 598–2260 → 3.8배
```

**① 게인이 3.8배 흔들린다.** 그게 R² 를 깎는 주범이고, 게인을 알고 나면 0.61 / 0.79 /
0.82 까지 오른다 — 그것이 사실상의 천장이다. TBZ·THI 의 0.64–0.67 은 그 천장의 81–82%
로, 낮은 게 아니라 **게인 산포가 허락하는 만큼**이다.

**② DQ 는 다르다. log–log R² 가 0.033 이다** — DQ 의 B 는 자기 농도를 거의 따라가지
않는다. 게인을 보정해도 0.61 에 그친다. 신호–농도 지수 0.52 와 잉크 바닥값이 여기서
직접 보인다. **§3 의 결론(DQ 한계는 물질)이 독립적으로 다시 확인된다.**

**③ 게인 추정은 이미 한계에 와 있다.** 참 농도 없이 스펙트럼만으로 계산되는 후보를
같은 자리에서 재봤다 (`gain_probe.py`, 65맵, 점수는 `B/ĝ` 대 `C` 의 R² 평균):

```
none            0.592   80%     보정 안 함
oracle          0.739  100%     총 B / 총 참농도 — 참값이 필요해 실제로는 못 씀
ink2137         0.664   90%     ← 지금 쓰는 것
ink_px_mean     0.667   90%
ink_px_med      0.663   90%
ink × area      0.656   89%
area            0.597   81%
B_total         0.529   72%
B_INK           0.221   30%
combo LOO-CV    0.629   85%     ← 교차검증하면 오히려 나빠진다 (과적합)
```

**지금 쓰는 잉크 2137 밴드가 이미 천장의 90% 이고, 무엇으로 바꿔도 안 오른다.**
픽셀 중앙값·기하평균·다변량 조합을 다 시도했다. 조합은 오라클에 맞추는 것이라
leave-one-out 으로 채점하면 85% 로 **떨어진다**. 남은 10%는 통계로 메울 수 없고 더 나은
물리적 손잡이(예: 기판 밝기의 직접 측정)가 있어야 한다.

> 부수 발견: **BLK 템플릿의 NNLS 계수는 항상 0 이다** — 기저에서 기판 몫을 INK 가 전부
> 가져간다. 블랭크 참조가 두 장일 이유가 없다.

DQ 는 게인을 완벽히 알아도 0.61 이라 여기서 얻을 것이 없다.

> ⚠ 위 단일성분 값과 이 혼합 값은 다른 양이다. 표에 올릴 때 섞지 말 것.

**기저에 블랭크·잉크를 넣어야 한다.** 분석물 3장만으로 맞추면 블랭크 맵의 기판·잉크
스펙트럼이 갈 곳이 없어 분석물 계수로 통째로 들어간다 — 그렇게 재면 DQ σ 가 9831,
LOD 가 77 µM 로 나와 3 µM 을 실제로 측정하고 있는 것과 모순된다. 그건 잡음이 아니라
적합 불가로 생긴 계통 오차다.

### SANTE 대조 — 정확도는 되는데 정밀도가 안 된다

SANTE/11312/2021 은 **회수율 70–120% · RSD ≤ 20%** 를 요구한다. 같은 조건을 다시
조제해 찍은 맵들 사이의 반복성(RSDr):

`DQ9-sus-relabeled` 12맵을 반복으로 넣었다 (학습에는 안 넣고 재현성 계산에만).
반복 있는 조건이 **6 → 18** 로 늘었다.

```
        조건수   RSDr 중앙        범위      평균 회수율   두 기준 동시 통과
DQ         5      26.7%      8.6–98.2%       101%          1/5
TBZ       14      58.1%     11.5–87.0%        88%          2/14
```

**평균 회수율은 88–120% 로 70–120% 안이거나 경계다. 못 넘는 것은 RSD 다.**
한계는 **치우침이 아니라 조제 사이 재현성**이다.

**THI 가 중앙 20.7% 로 SANTE 기준(≤20%)에 가장 가깝다** — 17조건 중 6개가 두 기준을

DQ 는 그대로 5조건인데, **재라벨본 12맵이 전부 DQ 3 µM** 이라 6 µM 하한 아래로 빠지기
때문이다.

> ### 2026-08-14 정정 — 한 조건 안에서 추정기가 섞여 있었다
>
> 2026-08-12 판은 `DQ 30.5% (11.0–52.9) · TBZ 50.8% (8.8–87.0) · THI 17.9%` 였다.

> 바로 아래 ⚠ 가 경고하던 상황이다. 이제 npz 가 들고 있는 경로를 그대로 쓴다.
>

> **THI 의 SANTE 통과가 7/17 → 6/17 로 줄어 기준을 아슬아슬하게 넘지 못한다.**

> ⚠ 이 표의 추정치는 **conc38 파이프라인이 아니라 B/기울기 경로로 다시 계산한 것**이다.
> 재라벨본은 conc38 을 거친 적이 없어서, 두 집단을 같은 추정기로 맞추려면 격자 쪽도
> 다시 계산해야 했다. 그래서 §2 앞머리의 2배 이내 통계(conc38 기준)와 **회수율 숫자가
> 조금 다르다.** 표를 섞어 쓰지 말 것.

안 된다. 표에도 열을 갈라 놓았다.

> `analysis/dq9-sus-reproducibility/README.md` 는 같은 자료로 조제간 조성 RMSE 0.130 ·

> 여기는 **농도 추정**의 산포다 — 다른 양이니 나란히 쓸 때 구분할 것.

```
       4          17.4%     8.8%   130
       8          15.7%     8.3%   130
      16          13.8%     7.7%   130
```

## 3. DQ 가 어려운 이유 — 물질이지 모델이 아니다

```
신호–농도 지수     DQ 0.52   vs   TBZ 1.09 · THI 1.04
Sips 지수 m        DQ 0.66   ·    TBZ 0.72 · THI 0.97      (THI 만 이상적 Langmuir)
친화도 K (M⁻¹)     DQ 7.05e3 ·    TBZ 3.39e4 · THI 3.10e4
경쟁 계수          ~0 — 경쟁자 없는 단일성분 검량에서도 같다
```

경쟁적 배제가 아니다. DQ 는 연성 donor 원자가 없는 bipyridinium 이가 양이온이라 은
표면에 정전기적으로만 흡착하고, TBZ·THI 는 각각 thiazole S / benzimidazole N 과
dithiocarbamate 로 화학흡착한다 — 기전은 해석이므로 "consistent with" 로 완충할 것.

**학습으로 못 넘는다.** blank / ink / sips / 조합 여섯 갈래를 다 시험했고 DQ 기울기
폭 19–24%p 가 그대로였다.

> ⚠ K 순서로 "TBZ 흡착이 가장 좋다"고 쓰지 말 것 — 부트스트랩 CI 가 겹치고 TBZ>THI
> 확률이 76%. 말할 수 있는 건 `DQ ≪ TBZ ≈ THI` 뿐.

앞서 나온 `3/333/333` 에서 DQ 0.4% 를 6.8% 로 읽은 것(회수 1518%)과 같은 현상이다.

## 5. 왜 학습 기반인가 — 정확도가 아니라 범용성

**가장 강한 근거는 격자가 아니라 글씨 맵이다.**
`analysis/trio-260812-concentration/` — 12 µM 씩 1:1:1 잉크로 "SERS" 를 쓴 실제 시료다.

```
                 NNLS              MLP+Physics        분주 참값
검출              THI 만 살아남음    DQ·TBZ·THI 3종      3종
조성             88.2 / 7.9 / 3.9   36.5 / 30.1 / 33.5  33.3 씩
농도 DQ                              10.1 ± 1.9 µM ✓     12 µM
농도 THI                             14.2 ± 2.8 µM ✓     12 µM
농도 TBZ                             2.7 ± 0.5 µM        (12 µM 분주)
```

**NNLS 는 THI 88% 로 무너지고 학습 모델은 1:1:1 을 복원한다.** DQ·THI 농도는 참값
1σ 안이다. TBZ 2.7 µM 은 틀린 값이 아니라 **SERS 유효 표면적재량**이다 — 펜으로 쓴
얇은 막에서 경쟁 서열 꼴찌인 TBZ 가 표면에서 밀려나고(액적에서는 안 밀린다),
맵은 표면을 재므로 2.7 이 그 표면의 참값이다. 같은 잉크가 표면에서 **10 : 2.7 : 14**
로 읽힌다 — 용액이 안 보여주는 침착 효과를 맵이 분해한다.

이것이 액적 격자보다 강한 이유: **도포 방식이 다른 실제 시료**이고, 선형 분해가
완전히 무너지는 자리이며, 조성·검출·농도가 한 맵에서 동시에 나온다.

나머지 근거는 부차적이다.
① 격자에서는 **고농도 삼원**에서만 덜 무너진다 (아래 표, n=7).
② NNLS 가 **못 하는 절대농도 판독**을 준다.
③ 검출 판정은 **대등하다** — `bench64` AUC 는 NNLS 0.931 · MLP 0.921 로 오히려 NNLS 가
   조금 높다. 전방위 우위를 주장하면 안 된다.

```
                  n     NNLS     학습      차이      학습 우세    p
저농도 65조건     65   15.1%   13.1%    +2.0%p     37/65     0.159  ← 유의하지 않음
고농도 이원       27   24.8%   21.5%    +3.3%p     13/27     0.679  ← 유의하지 않음
고농도 삼원        7   45.7%   28.6%   +17.0%p      6/7      0.047
```

NNLS 회수율(고농도) DQ 55 · TBZ 98 · **THI 393%**. 저농도에서는 109/120/112 로 멀쩡하다.

**남은 근거는 고농도 삼원 7조건 하나뿐이다.** 저농도의 2.0%p 는 유의하지 않고
(p=0.159, 학습 우세 37/65 로 동전던지기에 가깝다), 고농도 이원도 13/27 · p=0.68 이다.
삼원에서만 +17.0%p · p=0.047 로 갈리는데, 거기서도 학습 기반이 28.6% 라
"복원한다"가 아니라 **"덜 무너진다"** 까지만 말한다.
논지는 **어려운 구간일수록 학습 기반의 이점이 커진다** 는 것.
→ `CLAIM_nnls_vs_learned_2026-08-12.md`

> ### 2026-08-14 정정 — 저농도의 우위가 유의성을 잃었다
>
> 2026-08-12 판은 `저농도 +2.4%p · 41/65 · p=0.023` 으로 **유의**하다고 적고 있었다.
> 라벨을 고치고 다시 재니 `+2.0%p · 37/65 · p=0.159` 다. 고농도 이원은 조건이

>
> **표 1 을 인용할 때 "저농도에서도 학습이 낫다"고 쓰면 안 된다.** 주장의 무게가

## 5-1. 눌림 보정 — 기울기는 고쳐지는데 오차는 나빠진다

예측이 `p ≈ 0.6·t + b` 로 눌려 있어 `(p−b)/a` 로 펴 봤다. **학습 fold 에서만 a·b 를
적합하고 held-out 조건에 적용**했다 (held-out 을 포함해 적합하면 자기 답을 보고 보정하는
것이라 당연히 좋아진다).

```
보정        평균 오차   중앙    기울기 DQ/TBZ/THI    편향(%p)
none          13.1%   13.3%   0.59/0.61/0.64   +0.8/−1.2/+0.4
per-comp      15.1%   13.6%   0.94/0.96/1.01   +0.1/−0.6/+0.5    → 나빠짐
global        14.9%   14.2%   0.93/0.97/1.02   +1.4/−2.6/+1.2    → 나빠짐
```

**기울기 0.6 → 1.0, 편향 0 으로 깔끔하게 고쳐지는데 조성 오차는 늘어난다.** 펴면 분산이
1/a² ≈ 2.8배로 커지기 때문이다. 예측한 트레이드오프가 그대로 나왔다.

> 2026-08-14: 어제는 공통 보정이 **중앙값만** 12.1 → 11.5% 로 조금 나았는데,
> 라벨 정정 후에는 중앙값도 13.3 → 14.2% 로 **나빠진다.** 두 보정 다 어느 지표로도
> 이득이 없어져서 결론이 더 단순해졌다.

**→ 눌림 보정은 채택하지 않는다.** 기울기 <1 은 결함이 아니라 잡음 하의 평균회귀이고,
그걸 되돌리면 잡음도 같이 증폭된다.
