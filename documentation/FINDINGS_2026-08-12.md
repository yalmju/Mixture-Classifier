# 지금까지 확정된 내용 (2026-08-12)

숫자는 전부 **조건 단위 held-out**. 저농도는 64조건 완전격자(성분당 3·6·12·24 µM,
원액은 3배), 고농도는 `Ratio_mix` 32조건.

---

## 한 문단

성분당 **6 µM 이상**에서 세 성분의 **조성**이 복원되고(65조건 12.7%, 중앙 12.1% —
반복산포 하한 9.6% 에 근접), **농도**는 배수오차 2배 이내 **TBZ 87% · THI 89% · DQ 65%**
로 준정량 스크리닝 수준이다. **DQ 3 µM 은 혼합 LOD(2.90 µM) 바로 위라 농도를 보고하지
않고 `< LOD` 로 둔다.** 남은 한계는 알고리즘이 아니라 DQ 의 흡착 물리다.

## 1. 조성 — 된다

```
저농도 65조건   평균 12.7%   중앙 12.1%      채택 구성 blank+sips, 4-fold 조건단위
반복산포 하한    9.6%                         액적을 다시 조제했을 때의 산포
편향             DQ · TBZ · THI 모두 ±1%p 이내 — 셋 다 0과 구분 안 됨
```

우세 성분 일치 34/43 (참값 1·2위가 2%p 이내인 동률 22조건 제외).
오차 ≤20% 가 65조건 중 55개, 무정보 기준선(23.9% — 매번 "1/3씩" 이라 답할 때)보다
나은 것이 63개.

DQ 농도별 조성 오차: 3 µM 15.5% · 6 µM 11.8% · 12 µM 13.0% · 24 µM 13.9%.

## 2. 농도 — 6 µM 이상에서 준정량

```
성분당 6 µM 이상 (3 µM 제외)     2배 이내   3배 이내   중앙 배수오차   n
  DQ                               65%        92%        1.67×        60
  TBZ                              87%        98%        1.36×        61
  THI                              89%        98%        1.33×        61
  TBZ + THI                        88%        98%                    122
  세 성분 전체                     80%        96%                    182
```

3 µM 을 포함하면 DQ 55% · TBZ 79% · THI 87% 로 떨어진다. **떨어지는 것은 대부분
3 µM 이다** — DQ 19% · TBZ 50% · THI 81%.

> ⚠ **"정량(quantitative)" 이라 쓰지 말 것.** 2배(50–200%)는 SANTE(70–120%, RSD ≤20%)
> 보다 4배 느슨하다. **준정량 스크리닝**이 정확한 표현이다. 다만 액적 산포가 1.2–1.5배라
> 단일 액적으로는 2배가 물리적 하한에 가깝다.

### LOD / LOQ — 6 µM 하한이 독립적으로 확인된다

단일성분 검량, `LOD = 3.3σ/기울기` · `LOQ = 10σ/기울기`.
σ 는 블랭크 7맵(BLK 4 + INK 3)의 맵간 SD, 기울기는 30 µM 이하 검량점 5개(원점 통과).

```
        LOD (µM)   LOQ (µM)      3 µM 에서 2배 이내 회수
DQ        1.56       4.72               19%
TBZ       1.74       5.26               50%
THI       0.37       1.13               81%
```

**LOQ 가 3 µM 에서의 성능과 정확히 맞아떨어진다.** DQ·TBZ 는 LOQ 가 4.7–5.3 µM 이라
3 µM 은 정량 범위 밖이고, THI 는 LOQ 1.13 µM 이라 3 µM 도 안에 든다 — 회수 성능이
19 / 50 / 81% 로 갈리는 것과 순서·크기가 모두 일치한다. 앞서 회수율만 보고 경험적으로
잡은 **6 µM 보고 하한이 세 성분 LOQ 를 모두 넘기는 첫 격자 수준**이다.

> ⚠ 이건 **단일성분 LOD** 다. 문서의 "혼합 LOD 2.90 µM"(DQ)와 다른 양이다 — 혼합물에서는
> 다른 성분이 표면을 함께 덮어 더 높아진다. 표에 올릴 때 둘을 섞지 말 것.

**기저에 블랭크·잉크를 넣어야 한다.** 분석물 3장만으로 맞추면 블랭크 맵의 기판·잉크
스펙트럼이 갈 곳이 없어 분석물 계수로 통째로 들어간다 — 그렇게 재면 DQ σ 가 9831,
LOD 가 77 µM 로 나와 3 µM 을 실제로 측정하고 있는 것과 모순된다. 그건 잡음이 아니라
적합 불가로 생긴 계통 오차다.

### SANTE 대조 — 정확도는 되는데 정밀도가 안 된다

SANTE/11312/2021 은 **회수율 70–120% · RSD ≤ 20%** 를 요구한다. 같은 조건을 다시
조제해 찍은 맵들 사이의 반복성(RSDr):

```
        조건수   RSDr 중앙        범위      평균 회수율   두 기준 동시 통과
DQ         5      32.0%     11.6–52.0%       100%          0/5
TBZ        5      39.9%     12.9–55.9%       119%          1/5
THI        5      31.9%     14.4–50.5%       118%          2/5
```

**평균 회수율(100 · 119 · 118%)은 70–120% 안이거나 경계다. 못 넘는 것은 RSD 다** —
32–40% 로 기준의 1.6–2배. 즉 한계는 **치우침이 아니라 액적 사이 재현성**이다. 배수오차
2배가 물리적 하한에 가깝다는 앞의 서술과 같은 이야기다.

> ⚠ **반복이 있는 조건이 6개뿐이다** (3장 3조건 + 4장 3조건). SANTE 는 보통 반복 5회를
> 본다. 이 숫자는 **지시적(indicative)** 이지 공식 검증이 아니다 — n 을 반드시 같이 적을 것.

조건간 회수율 산포(65조건 전체)는 70–120% 안에 DQ 27% · TBZ 44% · THI 43% 가 든다.
**이건 RSD 가 아니다** — 조건이 다르면 회수율이 다른 게 당연하므로 SANTE 와 비교하면
안 된다. 표에도 열을 갈라 놓았다.

### 보고 문구

> 성분당 6 µM 이상에서 배수오차 2배 이내 TBZ 87% · THI 89%, 3배 이내 98%.
> DQ 는 같은 구간에서 2배 이내 65%(3배 92%)이고, 3 µM 조건은 혼합 LOD 2.90 µM 바로
> 위라 농도를 보고하지 않고 `< LOD` 로 둔다. 평균 회수율은 100–119% 로 SANTE 범위에
> 들지만 반복성 RSD 가 32–40% 로 기준(≤20%)을 넘으므로 **확인시험이 아니라 준정량
> 스크리닝**으로 위치시킨다 (반복 n=3–4, 6조건).

## 3. DQ 가 어려운 이유 — 물질이지 모델이 아니다

```
신호–농도 지수     DQ 0.52   vs   TBZ 1.09 · THI 1.04
Sips 지수 m        DQ 0.66   ·    TBZ 0.72 · THI 0.97      (THI 만 이상적 Langmuir)
친화도 K (M⁻¹)     DQ 7.05e3 ·    TBZ 3.39e4 · THI 3.10e4
경쟁 계수          ~0 — 경쟁자 없는 단일성분 검량에서도 같다
```

경쟁적 배제가 아니다. DQ 는 연성 donor 원자가 없는 bipyridinium 이가 양이온이라 은
표면에 정전기적으로만 흡착하고, TBZ·THI 는 각각 thiazole S / benzimidazole N 과
dithiocarbamate 로 화학흡착한다 — 기전은 해석이므로 "consistent with" 로 완충할 것.

**학습으로 못 넘는다.** blank / ink / sips / 조합 여섯 갈래를 다 시험했고 DQ 기울기
폭 19–24%p 가 그대로였다.

> ⚠ K 순서로 "TBZ 흡착이 가장 좋다"고 쓰지 말 것 — 부트스트랩 CI 가 겹치고 TBZ>THI
> 확률이 76%. 말할 수 있는 건 `DQ ≪ TBZ ≈ THI` 뿐.

## 4. 작업구간을 3–24 µM 로 한정하는 근거

등몰 삼원 시리즈, 참 조성은 네 농도 모두 33/33/33. NNLS 표면 조성:

```
성분당  10 µM   30 / 23 / 47
        33 µM   18 / 34 / 48
       100 µM    0 /  0 / 100     ← 순수 THI 와 코사인 0.99
       333 µM    0 /  0 / 100
```

고농도에서 THI 가 표면을 독점한다. **관측 사실로만 쓴다** — Langmuir 는 K 가 TBZ 최대라
정반대(약 30/40/30)를 예측한다.

**학습 구간 밖에서 모델을 쓰면 안 된다.** 같은 맵에서 MLP 는 표면에 DQ 가 0인데
46–52% 를 답한다. 조성 헤드가 softmax 라 "없음"을 말할 수 없고 OOD 가드가 없다.

## 5. 왜 학습 기반인가 — 정확도가 아니라 범용성

```
                  n     NNLS     학습      차이      학습 우세    p
저농도 65조건     65   15.1%   12.7%    +2.4%p     41/65     0.023
고농도 이원       24   20.8%   14.8%    +6.0%p     15/24     0.28   ← 유의하지 않음
고농도 삼원        7   45.7%   30.5%   +15.1%p      7/7      0.016
```

NNLS 회수율(고농도) DQ 57 · TBZ 53 · **THI 394%**. 저농도에서는 109/120/112 로 멀쩡하다.

**저농도만으로는 딥러닝을 정당화하지 못한다(2.4%p).** 갈리는 곳은 고농도 삼원이고,
거기서도 학습 기반이 30.5% 라 "복원한다"가 아니라 **"덜 무너진다"** 까지만 말한다.
논지는 **어려운 구간일수록 학습 기반의 이점이 커진다** 는 것.
→ `CLAIM_nnls_vs_learned_2026-08-12.md`
