# 지금까지 확정된 내용 (2026-08-12)

숫자는 전부 **조건 단위 held-out**. 저농도는 64조건 완전격자(성분당 3·6·12·24 µM,
원액은 3배), 고농도는 `Ratio_mix` 32조건.

---

## 한 문단

성분당 **6 µM 이상**에서 세 성분의 **조성**이 복원되고(65조건 12.7%, 중앙 12.1% —
반복산포 하한 9.6% 에 근접), **농도**는 배수오차 2배 이내 **TBZ 87% · THI 89% · DQ 65%**
로 준정량 스크리닝 수준이다. **DQ 3 µM 은 혼합 LOD(2.90 µM) 바로 위라 농도를 보고하지
않고 `< LOD` 로 둔다.** 남은 한계는 알고리즘이 아니라 DQ 의 흡착 물리다.

## 2. 농도 — 6 µM 이상에서 준정량

```
성분당 6 µM 이상 (3 µM 제외)     2배 이내   3배 이내   중앙 배수오차   n
  DQ                               65%        92%        1.67×        60
  TBZ                              87%        98%        1.36×        61
  THI                              89%        98%        1.33×        61
  TBZ + THI                        88%        98%                    122
  세 성분 전체                     80%        96%                    182
```

3 µM 을 포함하면 DQ 55% · TBZ 79% · THI 87% 로 떨어진다. **떨어지는 것은 대부분
3 µM 이다** — DQ 19% · TBZ 50% · THI 81%.

> ⚠ **"정량(quantitative)" 이라 쓰지 말 것.** 2배(50–200%)는 SANTE(70–120%, RSD ≤20%)
> 보다 4배 느슨하다. **준정량 스크리닝**이 정확한 표현이다. 다만 액적 산포가 1.2–1.5배라
> 단일 액적으로는 2배가 물리적 하한에 가깝다.

### LOD / LOQ — 6 µM 하한이 독립적으로 확인된다

단일성분 검량, `LOD = 3.3σ/기울기` · `LOQ = 10σ/기울기`.
σ 는 블랭크 7맵(BLK 4 + INK 3)의 맵간 SD, 기울기는 30 µM 이하 검량점 5개(원점 통과).

```
        LOD (µM)   LOQ (µM)      3 µM 에서 2배 이내 회수
DQ        1.56       4.72               19%
TBZ       1.74       5.26               50%
THI       0.37       1.13               81%
```

**LOQ 가 3 µM 에서의 성능과 정확히 맞아떨어진다.** DQ·TBZ 는 LOQ 가 4.7–5.3 µM 이라
3 µM 은 정량 범위 밖이고, THI 는 LOQ 1.13 µM 이라 3 µM 도 안에 든다 — 회수 성능이
19 / 50 / 81% 로 갈리는 것과 순서·크기가 모두 일치한다. 앞서 회수율만 보고 경험적으로
잡은 **6 µM 보고 하한이 세 성분 LOQ 를 모두 넘기는 첫 격자 수준**이다.

### 혼합 LOD — 감도는 별로 안 떨어진다

64조건 격자 65맵에서 **자기 농도에 대한 B 의 기울기**를 직접 재고, 같은 블랭크 σ 를 쓴다.

```
        혼합 기울기   단일 대비   혼합 LOD (µM)   혼합 LOQ (µM)
DQ          830        82%           1.90            5.77
TBZ        1252       118%           1.47            4.46
THI        1776        76%           0.49            1.49
```

DQ 1.90 µM 은 문서의 혼합 LOD 2.90 µM 과 같은 크기다. **검출 감도 자체는 혼합물에서
크게 안 떨어진다**(76–118%).

> ⚠ TBZ 가 118% 로 1을 넘는 건 비교 구간이 달라서다 — 단일 기울기는 0.1–10 µM,
> 혼합 기울기는 3–24 µM 에서 왔다. 정밀한 비교로 읽지 말 것.

**그런데 B 가 자기 농도를 잘 안 따라간다.** 혼합물에서 B 대 자기 농도의 R² 는
DQ 0.47 · TBZ 0.64 · THI 0.67 이다. 잔차 σ 로 LOD 를 다시 계산하면 16–22 µM 로 작업구간
전체를 덮어버린다.

**이것이 판독 경로가 raw B 가 아닌 이유다.** 단일 맵의 NNLS 계수 하나로는 혼합물에서
농도를 못 읽는다 — 그래서 조성은 학습 모델이, 농도는 응답계수 + 게인이 담당한다.
`lod_mixture.csv` 에 두 σ 기준을 다 넣어뒀으니 **어느 쪽인지 밝히고 인용할 것.**

R² 0.47–0.67 이 낮은지 높은지는 무엇과 겨루느냐로 정해진다. 같은 65맵에서 판독 방식만
바꿔 보면:

```
                 B vs C 선형   log B vs log C   조성비 vs 참조성   게인 보정 후
DQ                  0.471          0.033           0.486           0.608
TBZ                 0.639          0.709           0.618           0.788
THI                 0.666          0.727           0.740           0.821
맵별 게인(총B/총C) 산포:  5–95 백분위 598–2260 → 3.8배
```

**① 게인이 3.8배 흔들린다.** 그게 R² 를 깎는 주범이고, 게인을 알고 나면 0.61 / 0.79 /
0.82 까지 오른다 — 그것이 사실상의 천장이다. TBZ·THI 의 0.64–0.67 은 그 천장의 81–82%
로, 낮은 게 아니라 **게인 산포가 허락하는 만큼**이다.

**② DQ 는 다르다. log–log R² 가 0.033 이다** — DQ 의 B 는 자기 농도를 거의 따라가지
않는다. 게인을 보정해도 0.61 에 그친다. 신호–농도 지수 0.52 와 잉크 바닥값이 여기서
직접 보인다. **§3 의 결론(DQ 한계는 물질)이 독립적으로 다시 확인된다.**

**③ 게인 추정은 이미 한계에 와 있다.** 참 농도 없이 스펙트럼만으로 계산되는 후보를
같은 자리에서 재봤다 (`gain_probe.py`, 65맵, 점수는 `B/ĝ` 대 `C` 의 R² 평균):

```
none            0.592   80%     보정 안 함
oracle          0.739  100%     총 B / 총 참농도 — 참값이 필요해 실제로는 못 씀
ink2137         0.664   90%     ← 지금 쓰는 것
ink_px_mean     0.667   90%
ink_px_med      0.663   90%
ink × area      0.656   89%
area            0.597   81%
B_total         0.529   72%
B_INK           0.221   30%
combo LOO-CV    0.629   85%     ← 교차검증하면 오히려 나빠진다 (과적합)
```

**지금 쓰는 잉크 2137 밴드가 이미 천장의 90% 이고, 무엇으로 바꿔도 안 오른다.**
픽셀 중앙값·기하평균·다변량 조합을 다 시도했다. 조합은 오라클에 맞추는 것이라
leave-one-out 으로 채점하면 85% 로 **떨어진다**. 남은 10%는 통계로 메울 수 없고 더 나은
물리적 손잡이(예: 기판 밝기의 직접 측정)가 있어야 한다.

> 부수 발견: **BLK 템플릿의 NNLS 계수는 항상 0 이다** — 기저에서 기판 몫을 INK 가 전부
> 가져간다. 블랭크 참조가 두 장일 이유가 없다.

DQ 는 게인을 완벽히 알아도 0.61 이라 여기서 얻을 것이 없다.

> ⚠ 위 단일성분 값과 이 혼합 값은 다른 양이다. 표에 올릴 때 섞지 말 것.

**기저에 블랭크·잉크를 넣어야 한다.** 분석물 3장만으로 맞추면 블랭크 맵의 기판·잉크
스펙트럼이 갈 곳이 없어 분석물 계수로 통째로 들어간다 — 그렇게 재면 DQ σ 가 9831,
LOD 가 77 µM 로 나와 3 µM 을 실제로 측정하고 있는 것과 모순된다. 그건 잡음이 아니라
적합 불가로 생긴 계통 오차다.

### SANTE 대조 — 정확도는 되는데 정밀도가 안 된다

SANTE/11312/2021 은 **회수율 70–120% · RSD ≤ 20%** 를 요구한다. 같은 조건을 다시
조제해 찍은 맵들 사이의 반복성(RSDr):

```
        조건수   RSDr 중앙        범위      평균 회수율   두 기준 동시 통과
DQ         5      32.0%     11.6–52.0%       100%          0/5
TBZ        5      39.9%     12.9–55.9%       119%          1/5
THI        5      31.9%     14.4–50.5%       118%          2/5
```

**평균 회수율(100 · 119 · 118%)은 70–120% 안이거나 경계다. 못 넘는 것은 RSD 다** —
32–40% 로 기준의 1.6–2배. 즉 한계는 **치우침이 아니라 액적 사이 재현성**이다. 배수오차
2배가 물리적 하한에 가깝다는 앞의 서술과 같은 이야기다.

> ⚠ **반복이 있는 조건이 6개뿐이다** (3장 3조건 + 4장 3조건). SANTE 는 보통 반복 5회를
> 본다. 이 숫자는 **지시적(indicative)** 이지 공식 검증이 아니다 — n 을 반드시 같이 적을 것.

조건간 회수율 산포(65조건 전체)는 70–120% 안에 DQ 27% · TBZ 44% · THI 43% 가 든다.
**이건 RSD 가 아니다** — 조건이 다르면 회수율이 다른 게 당연하므로 SANTE 와 비교하면
안 된다. 표에도 열을 갈라 놓았다.

### 보고 문구

> 성분당 6 µM 이상에서 배수오차 2배 이내 TBZ 87% · THI 89%, 3배 이내 98%.
> DQ 는 같은 구간에서 2배 이내 65%(3배 92%)이고, 3 µM 조건은 혼합 LOD 2.90 µM 바로
> 위라 농도를 보고하지 않고 `< LOD` 로 둔다. 평균 회수율은 100–119% 로 SANTE 범위에
> 들지만 반복성 RSD 가 32–40% 로 기준(≤20%)을 넘으므로 **확인시험이 아니라 준정량
> 스크리닝**으로 위치시킨다 (반복 n=3–4, 6조건).

## 2-2. 학습곡선 — 더 찍어도 안 내려간다

저농도 조건 수만 바꾸고 같은 fold 로 채점 (`curve64.py`, 고농도 32맵은 항상 학습에 포함).

```
저농도 조건 수    평균 오차    SD      n
       0          24.4%    11.2%    65      고농도만으로 학습
       4          17.4%     9.2%   130
       8          15.8%     8.3%   130
      16          14.1%     7.9%   130
      24          13.2%     7.3%   130
      32          13.4%     7.6%   130
      40          12.6%     7.2%   130
      48          12.5%     6.7%   113
반복산포 하한       9.6%
```

**24조건에서 이미 평평해진다.** 24 → 48 로 두 배 늘려도 13.2 → 12.5%, 0.7%p 뿐이다.
앞의 4→16 구간이 3.3%p 를 벌어들인 것과 대비된다. 남은 2.9%p 는 반복산포라 조건을
더 찍어서는 못 줄인다.

**→ 조건을 더 측정할 이유가 없다.** 64조건 격자는 충분하고, 다음 개선은 데이터 양이
아니라 액적 재현성(측정 설계)에서 와야 한다. 앞의 게인 추정 결론(§5)과 같은 지점을
가리킨다.

> 35조건 시절 `curve38.py` 는 "남은 32조건을 찍을 값어치가 있는가"를 물었고 답은 예였다.
> 지금 같은 질문의 답은 아니오다. 두 곡선은 데이터 규약이 달라(DQ9-sus·중복 처리)
> 캐시도 따로 쓴다 — 겹쳐 그리지 말 것.

## 3. DQ 가 어려운 이유 — 물질이지 모델이 아니다

```
신호–농도 지수     DQ 0.52   vs   TBZ 1.09 · THI 1.04
Sips 지수 m        DQ 0.66   ·    TBZ 0.72 · THI 0.97      (THI 만 이상적 Langmuir)
친화도 K (M⁻¹)     DQ 7.05e3 ·    TBZ 3.39e4 · THI 3.10e4
경쟁 계수          ~0 — 경쟁자 없는 단일성분 검량에서도 같다
```

경쟁적 배제가 아니다. DQ 는 연성 donor 원자가 없는 bipyridinium 이가 양이온이라 은
표면에 정전기적으로만 흡착하고, TBZ·THI 는 각각 thiazole S / benzimidazole N 과
dithiocarbamate 로 화학흡착한다 — 기전은 해석이므로 "consistent with" 로 완충할 것.

**학습으로 못 넘는다.** blank / ink / sips / 조합 여섯 갈래를 다 시험했고 DQ 기울기
폭 19–24%p 가 그대로였다.

> ⚠ K 순서로 "TBZ 흡착이 가장 좋다"고 쓰지 말 것 — 부트스트랩 CI 가 겹치고 TBZ>THI
> 확률이 76%. 말할 수 있는 건 `DQ ≪ TBZ ≈ THI` 뿐.

## 3-1. 음성 대조 — DQ 는 없을 때도 있다고 한다

새로 측정할 필요가 없었다. **고농도 이원 24조건은 한 성분이 진짜 0** 이라 이미 성분별
음성 대조다 ("thiram 만 있고 TBZ 없는 시료" 가 `THI1000` 계열).

```
참값이 0 일 때 예측한 분율      n    중앙     평균    95백분위    최대
DQ                              9   11.80%  13.54%   30.74%   33.90%
TBZ                             9    1.70%   4.00%   11.66%   13.90%
THI                             8    0.00%   5.81%   29.80%   45.20%
```

문턱별 (오탐률 / 실제 있을 때의 검출률):

```
문턱      DQ              TBZ             THI
 2%    100% / 99%       44% / 98%       12% / 99%
 5%     56% / 99%       33% / 94%       12% / 98%
15%     44% / 90%        0% / 84%       12% / 89%
20%     22% / 85%        0% / 73%       12% / 82%
```

**TBZ 는 15% 문턱에서 오탐 0% · 검출 84% 로 쓸 만한 판정선이 있다.**
THI 는 2% 에서 검출 99% 지만 오탐 12% 가 문턱을 올려도 안 내려간다 — 한 조건이
끝까지 45% 를 답한다.

**DQ 는 쓸 만한 문턱이 없다.** 20% 까지 올려도 오탐 22% 이고 그때 검출은 85% 로 떨어진다.
§3 의 DQ 바닥값이 여기서 가장 직접적으로 보인다 — 없는데 11.8%(중앙)를 답한다.
앞서 나온 `10/1000/1000` 에서 DQ 0.5% 를 8.9% 로 읽은 것(회수 1792%)과 같은 현상이다.

> ⚠ 성분당 n=8–9 다. 방향은 분명하지만 문턱 값 자체는 지시적이다.
> 조성 헤드는 softmax 라 0 을 못 뱉는다 — "절대 0 이 아니다" 가 아니라 **얼마나 작으냐**
> 로 읽어야 한다.

**보고할 때:** DQ 는 존재 판정을 하지 말고 조성 성분으로만 쓰거나, `< LOD` 처리와 함께
"검출 여부를 단정하지 않는다"고 명시한다.

## 4. 작업구간을 3–24 µM 로 한정하는 근거

등몰 삼원 시리즈, 참 조성은 네 농도 모두 33/33/33. NNLS 표면 조성:

```
성분당  10 µM   30 / 23 / 47
        33 µM   18 / 34 / 48
       100 µM    0 /  0 / 100     ← 순수 THI 와 코사인 0.99
       333 µM    0 /  0 / 100
```

고농도에서 THI 가 표면을 독점한다. **관측 사실로만 쓴다** — Langmuir 는 K 가 TBZ 최대라
정반대(약 30/40/30)를 예측한다.

**학습 구간 밖에서 모델을 쓰면 안 된다.** 같은 맵에서 MLP 는 표면에 DQ 가 0인데
46–52% 를 답한다. 조성 헤드가 softmax 라 "없음"을 말할 수 없고 OOD 가드가 없다.

## 5. 왜 학습 기반인가 — 정확도가 아니라 범용성

```
                  n     NNLS     학습      차이      학습 우세    p
저농도 65조건     65   15.1%   12.7%    +2.4%p     41/65     0.023
```

## 5-1. 눌림 보정 — 기울기는 고쳐지는데 오차는 나빠진다

예측이 `p ≈ 0.6·t + b` 로 눌려 있어 `(p−b)/a` 로 펴 봤다. **학습 fold 에서만 a·b 를
적합하고 held-out 조건에 적용**했다 (held-out 을 포함해 적합하면 자기 답을 보고 보정하는
것이라 당연히 좋아진다).

```
보정        평균 오차   중앙    기울기 DQ/TBZ/THI    편향(%p)
none          12.7%   12.1%   0.59/0.64/0.64   −2.0/+1.2/+0.7
per-comp      14.5%   13.5%   0.95/0.99/1.00   −0.1/−0.3/+0.4    p=0.050 → 나빠짐
global        13.6%   11.5%   0.92/1.00/1.01   −2.9/+1.3/+1.5    p=0.35  → 차이 없음
```

**기울기 0.6 → 1.0, 편향 0 으로 갈끔하게 고쳐지는데 조성 오차는 늘어난다.** 펴면 분산이
1/a² ≈ 2.8배로 커지기 때문이다. 예측한 트레이드오프가 그대로 나왔다.

공통 보정은 중앙값만 12.1 → 11.5% 로 조금 낫다(평균은 나빠짐) — 전형적 조건은 도움받고
꼬리가 더 나빠진다. 이득이라 부를 정도는 아니다.

**→ 눌림 보정은 채택하지 않는다.** 기울기 <1 은 결함이 아니라 잡음 하의 평균회귀이고,
그걸 되돌리면 잡음도 같이 증폭된다.
