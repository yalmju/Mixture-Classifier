# 선형 분해 대 학습 기반 — 무엇을 주장할 수 있나 (2026-08-12)

`PAPER_FIGURES_2026-08-11.md` §3 의 "NNLS 18.4% vs 학습 11.2%" 를 **대체한다.**
그 숫자는 특징 단위에 따라 크게 흔들려서 논지를 못 버틴다.

---

## 채택 문장

> 선형 분해는 고농도 삼원에서 완전히 무너진다 (45.7%, THI 회수율 394% — 표면을 THI 가
> 독점). 학습 기반은 같은 조건에서 30.5% 로 7/7 모두 우세하지만 여전히 세 성분을
> 가르지 못한다. 두 방법의 격차는 저농도 2.4%p 에서 고농도 삼원 15.1%p 로 벌어지며,
> **어려운 구간일수록 학습 기반의 이점이 커진다.**

논지는 "학습이 더 정확하다" 가 아니라 **"학습이 더 범용적이다"** 다. 저농도만 보면
격차가 2.4%p 라 딥러닝을 정당화하지 못한다. 삼원 고농도에서 갈린다.

## 근거 — 전부 짝지어 비교(paired), 같은 맵·같은 전처리

### 저농도 65조건 격자 (맵 평균 스펙트럼 단위)

```
NNLS   평균 15.1%   중앙 14.9%      학습 없음
MLP    평균 12.7%   중앙 12.1%      leave-one-condition-out, blank+sips
차이   +2.4%p · MLP 우세 41/65 · 대응 t p=0.023 · Wilcoxon p=0.036
반복산포 하한 9.6% 까지의 거리를 5.5%p → 3.1%p 로 44% 좁힌다
```

### 고농도 Ratio_mix 32조건

MLP 는 `retrain_all.txt` (4-fold 조건단위 held-out, `blank` 구성), NNLS 는 학습 없음.

```
        n     NNLS     MLP      차이     MLP 우세   Wilcoxon p
전체    32   28.7%   19.5%    +9.2%p    23/32      0.015
이원    24   20.8%   14.8%    +6.0%p    15/24      0.28     ← 유의하지 않음
삼원     7   45.7%   30.5%   +15.1%p     7/7       0.016
```

성분별 NNLS 회수율(고농도): DQ 57% · TBZ 53% · **THI 394%**.
저농도에서는 109 / 120 / 112% 로 셋 다 멀쩡하다 — 그래서 삼각형이 저농도에서는
초록이고 고농도에서만 노랗다.

## 표 1 — 다섯 방법, 같은 픽셀·같은 fold (2026-08-13 확정)

`bench64.py 120 20 100 120`, 13.5시간. 112맵 · 20픽셀/맵 · **base 구성**(blank/sips 아님,
`benchmark_loo` 가 그 인자를 안 받는다) · RF 100트리 max_features=sqrt · CNN 도 같은
120 epoch.

**세 데이터셋을 한 판에 놓고 채점한다** — 저농도 64격자 + 고농도 `Ratio_mix` + `tert-new`,
DQ9-sus 제외, md5 중복 제외해서 112맵. **fold 단위는 농도조건이 아니라 조성비**라
112맵이 68개 비율군으로 묶인다 (같은 비율이면 농도가 달라도 한 fold 에서 통째로 빠진다 —
누출 방지에는 옳지만, 군 하나가 한 농도 구간을 뜻하지 않는다):

```
저농도 삼원 (64격자)      36군       고농도 이원 (한 성분 0)    25군
고농도 삼원                6군       혼합                        1군  ← 등몰 1:1:1 하나뿐
                                                                    (저농도 6/6/6·12/12/12·
                                                                     24/24/24 + 고농도 100µM)
```

즉 실제로 두 구간이 섞인 군은 **등몰 1:1:1 하나**이고, 나머지 67군은 한쪽 구간에서만 온다.
이원 25군은 전부 고농도다 — 저농도 격자는 세 성분이 모두 3 µM 이상이라 0 이 없다.

```
                 조성오차 평균 / 중앙    검출 AUC     MLP 대비 짝지은 차이 (68조건)
MLP                  15.8 / 13.5         0.904        —
PLS                  16.7 / 14.6         0.899        +0.9%p  37/68  p=0.46   ← 구분 안 됨
Random Forest        19.3 / 16.8         0.896        +3.5%p  50/68  p=0.0002
NNLS                 21.1 / 14.9         0.908        +5.2%p  41/68  p=0.0063
1D-CNN               34.0 / 31.6         0.687       +18.1%p  62/68  p<0.0001
```

**검출 AUC 는 CNN 을 빼면 전부 0.896–0.908 로 동률이고, 최고값은 NNLS 다.**
존재 판정은 어느 방법으로도 되고, 갈리는 것은 조성뿐이다. 패널 e 로 학습 우위를
주장하지 말 것.

**1D-CNN 34.0% 를 "CNN 은 안 된다" 로 읽지 말 것.** epoch 은 같지만 **물리 사전학습을
MLP 만 받고**(`benchmark_loo` 가 `pre` 를 mlp 갈래에만 넘긴다), 학습이 full-batch 라
120 epoch 이 곧 gradient 업데이트 120번이다. "이 설정의 1D-CNN" 까지만 말한다.

> ⚠ 이 표의 MLP 15.8% 를 본문 조성 12.9% 와 같은 줄에 쓰지 말 것 — 구성(base vs
> blank+sips) · 특징(픽셀 vs 맵평균) · fold 정의(조성비 vs 농도조건)가 전부 다르다.
> 표 1 은 **한 프로토콜 안에서의 순위**이지 각 방법의 절대 성능이 아니다.

## 왜 PLS 가 아니라 MLP 인가

**표 1 만 보면 PLS 는 MLP 와 구분되지 않는다 (16.7 vs 15.8, p=0.46).** 오히려 논문의
주력 구간인 저농도 삼원 격자에서는 PLS 가 조금 낫다. 그러니 "PLS 보다 정확해서" 는
근거가 될 수 없다. 갈리는 곳은 세 군데다.

```
구간                  n     MLP     PLS    NNLS      RF     CNN      MLP−PLS
저농도 삼원 (64격자)  36   12.8%   11.4%   13.9%   14.0%   26.4%   −1.4%p  p=0.062  ← PLS 우세
고농도 삼원            6   24.8%   26.4%   46.4%   28.5%   26.4%   +1.6%p  p=0.31
고농도 이원           25   18.4%   22.5%   25.8%   25.4%   47.9%   +4.1%p  p=0.002  ← 갈리는 곳
혼합 (등몰 1:1:1)      1    6.7%    2.8%   10.4%    3.0%    4.8%      —
```

**① 어려운 구간에서 갈린다 — NNLS 와 같은 논지의 반복이다.** 고농도 이원에서 +4.1%p,
p=0.002. 정직하게 쓰면: *작업구간 안에서는 선형 방법으로도 되지만, 구간을 벗어날수록
학습 기반이 덜 무너진다.*

> ⚠ **약점을 알고 쓸 것.** 저농도 격자 36군에서는 PLS 가 11.4% 로 MLP 12.8% 보다 낫고
> p=0.062 다 — 유의하지는 않지만 경계선이다. 리뷰어가 표 1 을 **작업구간(3–24 µM)에서만**
> 다시 계산하면 PLS 가 앞선 것처럼 보인다. 그래서 ①만으로는 부족하고 ②가 필요하다.
> 고농도 삼원은 n=6 이라 방향(+1.6%p)만 있고 근거로 못 쓴다.

**② 편향이 3배 작다 — 채택 구성을 고를 때 쓴 것과 같은 잣대다.** `blank+sips` 를 고른
이유가 오차가 아니라 편향이었다. 같은 자로 재면:

```
성분별 편향 (예측−참, %p, 68조건)      DQ      TBZ      THI     최대 |편향|
MLP                                  +0.31   +0.20   −0.51       0.51
PLS                                  +0.02   −1.51   +1.49       1.51
NNLS                                 −9.32   −6.10  +15.41      15.41
```

**③ 구조가 조성을 보장한다.** MLP 는 softmax 머리라 출력이 애초에 비음수·합 1 이다.
PLS 는 제약 없는 회귀라 음수 예측을 잘라내고 다시 정규화해야 한다
(`dl_model._fit_predict`). 조성을 답으로 내는 문제에서 이건 사후 보정이지 모델이 아니다.

**④ 파이프라인이 하나로 이어진다.** 물리 사전학습(등온선 시뮬레이션) · 농도 머리 ·
픽셀 단위 적용이 전부 같은 망에 붙어 있다. 채택 구성(조성 12.9%, 편향 ±1%p 이내)은
MLP 경로에만 존재한다. PLS 로 갈아타면 그 셋을 따로 다시 만들어야 한다.

> ①②는 데이터가 받쳐 주는 논거이고, ③④는 설계상의 논거다. **논문에는 ①을 앞세우고
> ②를 뒷받침으로 쓴다.** ③④는 방법 절에 한 줄씩이면 충분하다.
> 반대로 **"PLS 보다 정확하다" 는 쓸 수 없다** — 전체 p=0.46, 저농도는 오히려 PLS 우세.

## 쓰면 안 되는 것

```
✗ "고농도에서 MLP 는 조성을 복원한다"      삼원 30.5% 다. 세 성분을 못 가른다.
                                          "덜 무너진다" 까지만.
✗ 이원 결과를 근거로 쓰기 (NNLS 비교)       p=0.28. 유의하지 않다.
                                          단 PLS 비교의 이원은 p=0.002 로 유의하다 — 다른 표다.
✗ "NNLS 18.4% vs MLP 11.2%"                특징 단위에 따라 흔들린다(아래).
✗ "선형 분해로는 부족하다" 를 NNLS 하나로   PLS 가 16.7% 로 따라온다. 표 1 을 실으면
                                          바로 반박당한다.
✗ 검출 AUC 로 학습 우위 주장                CNN 빼고 전부 0.90 언저리, 최고는 NNLS.
✗ 패널 a(고농도)와 g(저농도)를 나란히 놓고
  "NNLS vs MLP" 로 읽히게 하기               세트가 다르다. 같은 세트로 비교해야 한다.
```

## NNLS 기준선이 네 값인 이유

```
27.6%   문서 원본 — 오래된 특징
18.4%   같은 특징 재현 — curve38_feats.npz, 픽셀 단위, 35 공통조건
15.1%   2026-08-12 — 맵 평균 스펙트럼, 65조건
21.1%   2026-08-13 bench64 — 픽셀 20/맵, 조성비 fold, 저·고농도 한 판   ← 표 1 의 값
```

**특징 단위와 fold 정의가 원인이다.** 픽셀로 돌리면 NNLS 가 나빠지고 맵 평균으로
돌리면 좋아진다. MLP 는 픽셀로 학습해 맵 평균으로 적용하므로 어느 쪽도 자동으로
공정하지 않다. **"NNLS 의 진짜 값" 은 없다** — 표 1 은 한 프로토콜 안의 순위로만 읽고,
본문에서 NNLS 를 인용할 때 어느 줄인지 반드시 밝힌다.
