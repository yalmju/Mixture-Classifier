# 선형 분해 대 학습 기반 — 무엇을 주장할 수 있나 (2026-08-12)

`PAPER_FIGURES_2026-08-11.md` §3 의 "NNLS 18.4% vs 학습 11.2%" 를 **대체한다.**
그 숫자는 특징 단위에 따라 크게 흔들려서 논지를 못 버틴다.

---

## 채택 문장

> 선형 분해는 고농도 삼원에서 완전히 무너진다 (45.7%, THI 회수율 394% — 표면을 THI 가
> 독점). 학습 기반은 같은 조건에서 30.5% 로 7/7 모두 우세하지만 여전히 세 성분을
> 가르지 못한다. 두 방법의 격차는 저농도 2.4%p 에서 고농도 삼원 15.1%p 로 벌어지며,
> **어려운 구간일수록 학습 기반의 이점이 커진다.**

논지는 "학습이 더 정확하다" 가 아니라 **"학습이 더 범용적이다"** 다. 저농도만 보면
격차가 2.4%p 라 딥러닝을 정당화하지 못한다. 삼원 고농도에서 갈린다.

---

## 근거 — 전부 짝지어 비교(paired), 같은 맵·같은 전처리

### 저농도 65조건 격자 (맵 평균 스펙트럼 단위)

```
NNLS   평균 15.1%   중앙 14.9%      학습 없음
MLP    평균 12.7%   중앙 12.1%      leave-one-condition-out, blank+sips
차이   +2.4%p · MLP 우세 41/65 · 대응 t p=0.023 · Wilcoxon p=0.036
반복산포 하한 9.6% 까지의 거리를 5.5%p → 3.1%p 로 44% 좁힌다
```

### 고농도 Ratio_mix 32조건

MLP 는 `retrain_all.txt` (4-fold 조건단위 held-out, `blank` 구성), NNLS 는 학습 없음.

```
        n     NNLS     MLP      차이     MLP 우세   Wilcoxon p
전체    32   28.7%   19.5%    +9.2%p    23/32      0.015
이원    24   20.8%   14.8%    +6.0%p    15/24      0.28     ← 유의하지 않음
삼원     7   45.7%   30.5%   +15.1%p     7/7       0.016
```

성분별 NNLS 회수율(고농도): DQ 57% · TBZ 53% · **THI 394%**.
저농도에서는 109 / 120 / 112% 로 셋 다 멀쩡하다 — 그래서 삼각형이 저농도에서는
초록이고 고농도에서만 노랗다.

## NNLS 기준선이 세 값인 이유

```
27.6%   문서 원본 — 오래된 특징
18.4%   같은 특징 재현 — curve38_feats.npz, 픽셀 단위, 35 공통조건
15.1%   2026-08-12 — 맵 평균 스펙트럼, 65조건
```

**특징 단위가 원인이다.** 픽셀로 돌리면 NNLS 가 나빠지고 맵 평균으로 돌리면 좋아진다.
MLP 는 픽셀로 학습해 맵 평균으로 적용하므로 어느 쪽도 자동으로 공정하지 않다.

`bench64.py` 가 다섯 방법을 **같은 픽셀·같은 fold** 로 채점한다 (px_per_map=20:
픽셀로 학습·예측하고 맵 안에서 평균). 표 1 은 그 결과로 확정한다. 그때까지 표 1 의
NNLS 숫자를 인쇄하지 말 것.

## 재현

```bash
cd documentation/scripts
python3 -u export_nnls.py --set low     # 저농도 NNLS  → panel_a_nnls_conditions_low.csv
python3 -u export_nnls.py --set high    # 고농도 NNLS  → panel_a_nnls_conditions_high.csv
python3 -u bench64.py 120 20            # 5방법 픽셀 단위 비교 (1–3시간)
```

MLP 쪽 숫자는 `piemap_260812/piemap_data.pkl`(저농도) 와
`64conditions/retrain_all.txt`(고농도) 에서 온다.
