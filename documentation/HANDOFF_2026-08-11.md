## 이번 세션에서 확정된 것

**① DQ 한계는 알고리즘이 아니라 흡착 물리다.** 신호–농도 지수 DQ 0.52 vs TBZ 1.09 ·
THI 1.04. **경쟁 계수는 ~0** 이라 매몰이 아니고, 경쟁자 없는 단일성분 검량에서도 같다.
Sips 지수 0.66 / 0.72 / 0.97 — THI 만 이상적 Langmuir. → `dq-adsorption-physics` 메모리

**② 잉크가 DQ 를 오염시킨다.** `dataset.py:29` 가 `"ink"` 를 blank 별칭으로 분류해 템플릿에서
빼는데, INK·DQ 코사인이 0.732 로 DQ·TBZ(0.664)보다 닮았고 INK 계수가 DQ 의 1.9배다.
DQ 계수 절편이 중앙값의 98%. BLK 는 무죄, 범인은 잉크.

**③ 함정 두 개를 고쳤다.**
- 앱의 분할 단위가 조성이 아니라 **맵**이었다 → 조성 튜플로 수정 (풀링 키는 맵 그대로)
- `include_blank=True` 가 **물리 사전학습을 조용히 껐다** → 분석물 개수로 게이트 비교하고
  사전학습 라벨에 blank 열(0) 추가. 고치니 13.7% → 12.4%

**④ 라이브러리에 추가한 것** (기본값은 전부 기존 동작 유지, bit-identical 확인)
