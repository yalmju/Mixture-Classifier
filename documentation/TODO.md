## 1. ✅ LOD — 확정됨

`LOD = 3.3 · σ_blank / 기울기`, blank = **INK 맵**(종이+잉크, 분석물만 없음)을
**INK 포함 전체 템플릿**으로 NNLS 투영, 기울기는 포화 전 구간(0.1–10 µM) OLS,
σ는 맵 400픽셀 기준(`σ_pixel/√400`).

| | LOD | µg/L | 단일 픽셀이면 |
|---|---|---|---|
| DQ | **84 nM** | 15.5 | 1.69 µM |
| TBZ | **94 nM** | 18.9 | 1.88 µM |
| THI | **83 nM** | 20.0 | 1.67 µM |

세션 중 값이 흔들린 원인 세 가지 — blank를 BLK로 잡음, readout에서 INK 누락,
격자점(onset)을 LOD로 읽음 — 모두 정정. 검량선 세트는 `Pest/Standard/260729/`로 고정.

> 남은 선택지 하나: 규제치와 비교하려면 **전처리 배율**(시료 g → 용매 mL)이 필요하다.
> 현재 측정은 전부 표준용액이라 나뭇잎 단계에서 정해진다.

## 4. 참고: sweat 논문의 정량 방법과 무엇이 다른가

> Park, Heo, Choi, **Lee** et al., *Wearable plasmonic SERS patch for quantitative sweat
> metabolite profiling via dual-track spectral inference* (revised manuscript).
> 본인이 공저자이므로 방법론을 그대로 인용해 설계 근거로 쓸 수 있습니다.

### 그 논문이 한 것

| 항목 | 내용 |
|---|---|
| 대상 | urea (0.5–10 mM) · uric acid (5–100 µM) · paraxanthine (1–50 µM) |
| **설계** | **완전요인 5수준 × 3물질 = 125 혼합물.** 각 물질을 **독립적으로** 변화 |
| 밴드 선택 | 구조적으로 귀속 가능 · 전 구간 위치 안정 · **단조 세기 증가** · 간섭과 최소 중첩 |
| 검량 | 각 물질 **자기 범위 안에서 선형**, R² **0.98 / 0.96 / 0.95** |
| 반복 | 검량점당 **5회**, 혼합물점당 **25회** |
| 모델 | dual-track — 고농도(urea·uric acid)는 1D ResNet 직접 회귀, 미량(paraxanthine)은 **unmixing 후 잔차 스펙트럼에 CNN + Huber 앙상블** |
| 전처리 | 1차 미분 평활 + 표준화 |
| 결과 | R² ≈ 0.99 (urea·uric acid), **0.89** (paraxanthine) |

### 우리 것과의 차이 — 셋 다 설계 차이지 모델 차이가 아님

| | sweat 논문 | pesticide (현재) |
|---|---|---|
| **농도 축** | 조성과 **직교** (완전요인) | 조성과 **완전히 얽힘** — 같은 비율을 다른 농도에서 찍은 맵 **0/34** |
| **측정 구간** | 각 물질 **선형 구간 안**, R² 0.95–0.98 | **포화 구간**. THI 반포화 31.7 µM인데 혼합물 3.3–500 µM |
| **혼합물 반복** | 점당 25회 | **없음** |
| 샘플 수 | 125 (3D 공간을 채움) | 34 (대부분 심플렉스 모서리, 삼성분 7개) |
| 밴드 선택 | 단조성 + 최소 중첩 기준 | VIP (같은 발상) — **여기는 일치** |

### 왜 그쪽은 되고 여기는 안 되나 — 문제의 종류가 다름

| | sweat 논문 | pesticide |
|---|---|---|
| 어려움의 정체 | **masking** — paraxanthine 신호가 urea에 **묻힘** | **saturation** — 표면이 차서 신호가 **안 변함** |
| 복원 가능? | **가능.** 신호는 있고 큰 신호 아래 있을 뿐 → unmixing + 잔차 CNN이 파냄 | **불가능.** 전달 단계에서 정보가 사라짐 |

**묻힌 건 파낼 수 있지만 애초에 안 실린 건 못 파냅니다.** dual-track이 대단해서가 아니라
**데이터에 정보가 있었기 때문에** 작동한 것입니다. 같은 프레임워크를 이 데이터에 씌워도 결과는 같습니다.

물리도 다릅니다 — urea/uric acid/paraxanthine은 약하게 붙는 소분자라 단분자층 포화까지 안 갑니다.
여기는 thiram이 S로 화학흡착해 표면을 점령합니다 (K가 diquat의 18배).

### 그대로 가져올 레시피

1. 각 물질의 **선형 구간 확인** — 여기선 이미 완료: DQ 100–1000, TBZ 0.1–50, THI 0.5–5 µM
2. **각자 자기 구간 안에서 완전요인** — 3수준×3물질 = 27맵이 최소 (그 논문은 5수준 125맵)
3. **조건당 반복 ≥3회**
4. 밴드 선택 기준은 이미 동등 (VIP ≈ 단조성 + 최소 중첩)

> ⚠️ **DQ가 걸림돌**입니다. 반응 구간이 100–1000 µM으로 1 dec뿐이라 수준을 나눌 여지가 좁습니다.
> §2-5(표면 개질)가 여기서 선택이 아니라 **전제**가 됩니다.

## 5. Real 탭 µM을 다시 켜려면 — 작업 농도 상자와 단계

### 지금 안 되는 이유는 농도대가 겹쳐서다

34맵은 세 물질을 비슷한 농도로 섞는다. 그러면 표면이 거의 꽉 찬다:

| 조건 | θ_DQ | θ_TBZ | θ_THI | **Σθ** |
|---|---|---|---|---|
| 167 µM씩 | 0.03 | 0.35 | 0.51 | **0.90** |
| 333 µM씩 | 0.03 | 0.37 | 0.54 | **0.95** |

포화라 농도를 올려도 θ가 안 움직이고, **DQ는 θ 0.03으로 표면에서 밀려난다**
(친화도가 17배 약한데 농도는 같으므로).

### 각자 자기 구간에 놓으면 풀린다

| 조건 | θ_DQ | θ_TBZ | θ_THI | Σθ | 응답 여력 |
|---|---|---|---|---|---|
| DQ 100 · TBZ 5 · THI 1 µM | 0.136 | 0.079 | 0.023 | **0.24** | **76%** |
| DQ 300 · TBZ 20 · THI 5 µM | 0.255 | 0.198 | 0.072 | 0.53 | 47% |

**권장 작업 상자** (각 약 1 decade, 셋 다 LOD의 10배 이상):

| | 하한 | 상한 |
|---|---|---|
| DQ | 30 µM | 300 µM |
| TBZ | 1 µM | 20 µM |
| THI | 0.2 µM | 5 µM |

sweat 논문도 같은 구조였다 — urea mM / uric acid µM / paraxanthine µM으로 **구간이
겹치지 않는데 각자 자기 범위에서 완전요인**을 돌렸다. 겹치지 않는 것이 문제가 아니라,
**겹치게 섞은 것**이 문제였다.

### 도달 가능한 목표 세 단계

| 목표 | 가능? | 조건 |
|---|---|---|
| **자릿수 반정량** | ✅ | 완전요인 27맵 + 위 작업 상자 |
| **2~3배 이내 µM** | 🟡 | 위 + 조건당 반복 ≥3회 |
| **±20% (SANTE 수준)** | ❌ | **내부표준 없이는 불가** — 기판 CV 37–50%가 천장 |

**설계로 풀리는 것**: 비율/농도 얽힘 · 포화 · DQ 밀림 → 재획득으로 해결
**설계로 안 풀리는 것**: 기판 gain 산포(CV 37–50%) → 내부표준 필요

→ Real 탭 µM은 **1단계에서 "semi-quantitative, order-of-magnitude" 라벨을 달고 재개 가능**.
2단계에서 라벨을 뗄 수 있고, 3단계는 기판 쪽 작업이 먼저다.

### 그 논문과 여기서 갈리는 지점 (§4와 별개로, µM 달성에 직결되는 것)

| | sweat 논문 | 여기 |
|---|---|---|
| **정규화** | **L2 정규화 적용** — 크기를 버리고 모양만 씀 | **L2 안 씀** — 농도가 크기에 있다고 보고 보존 |
| **평가 프로토콜** | 125조건 데이터에 대한 예측 대 실측. **held-out 분할이 본문에 기술돼 있지 않음** | **leave-one-map-out 34폴드** |
| 기판 | 수화 agarose 매트릭스 안에서 **in-situ 생성된 AuNP** (3D, 균질) | 종이 위 SERS ink (hot-spot 불균일, **CV 37–50%**) |
| 기판 CV | **본문에 없음** — 직접 비교 불가 | 37–50% (n=14) |
| 증강 | Monte Carlo 합성 4,000 + 실측 50× 오버샘플 | 물리 사전학습 (검량선 기반 시뮬레이션) — 같은 발상 |
| 학습 | LeakyReLU · AdamW · Huber · 300 epoch · batch 32 | ReLU · Adam · 가중 L1 · **6 epoch(선택)** · 풀배치 |
| 후처리 | 예측값에 adaptive background subtraction | 없음 |

> ⚠️ **L2 정규화가 핵심 갈림길이다.** 그쪽은 크기를 버리고도 농도를 맞혔는데, 완전요인이라
> **각 물질의 비선형 응답이 서로 달라 모양 자체가 총량에 따라 변하기 때문**이다.
> 얽힌 설계에서는 이 경로가 막히므로 우리는 크기를 보존했고, 그런데 크기가 gain에 오염돼
> 있었다(총신호 vs 총농도 R² 0.02). **완전요인을 확보하면 두 경로가 다 열린다.**

> ⚠️ **R² 0.99를 우리 22.8%와 나란히 인용하지 말 것.** 프로토콜이 다르다 —
> 우리 쪽은 맵 단위 held-out이고, 그쪽 본문에는 분할 기술이 없다. 인용할 때는
> **설계(완전요인·반복)를 근거로 삼고 성능 수치는 나란히 놓지 않는 것**이 안전하다.

## 6. 1:1:1 희석 계열 — 오늘 측정분, 무엇을 보는가

기존 `TBZ1000DQ1000THI1000`(equal-volume 기준 333 µM씩)을 희석.

### 왜 이 세트가 판별 장치인가

1:1:1에서는 농도가 다 같이 줄면 분모가 상쇄된다:

```
θ_i / θ_j  =  K_i·C_i / (K_j·C_j)  =  K_i / K_j
```

→ **표면 조성이 희석과 무관하게 고정**된다. 예측치 **DQ 4.1 / TBZ 42.2 / THI 53.7%**.
즉 **조성에는 희석 정보가 0**이다. 모델이 이 맵들에 서로 다른 µM을 내놓으면 진짜로 크기를
읽는 것이고, 전부 같은 값을 내놓으면 조성만 읽고 있던 것이다. 34맵으로는 불가능했던 구분이
이 한 세트로 된다.

### 예측 (INK 포함 등온선의 K로부터)

| 희석 | 각 농도 | Σθ | LOD 여유 |
|---|---|---|---|
| ×1 (기존) | 333 µM | 0.946 | ✓ |
| ×1/10 | 33.3 µM | 0.638 | ✓ |
| ×1/30 | 11.1 µM | 0.370 | ✓ |
| ×1/100 | 3.33 µM | 0.150 | ✓ |
| ×1/300 | 1.11 µM | 0.055 | ✓ |
| ×1/1000 | 0.333 µM | 0.017 | ✓ (LOD의 3.7배) |
| ×1/3000 | 0.111 µM | 0.006 | ⚠ marginal — 여기까지 가지 말 것 |

농도 1000배에 Σθ는 **56배**만 변한다(위쪽이 포화로 압축). **×1/30 아래는 거의 비례**
(×1/100 → ×1/1000에서 농도 10배에 Σθ 8.8배) → **희석 쪽을 촘촘히 잡을 것.**

### 측정 후 확인할 것

1. **물리 검증** — 표면 조성이 정말 4.1 / 42.2 / 53.7%로 유지되는가.
   유지되면 K가 맞다는 **모델을 안 거친 독립 증거**. 변하면 단일성분 K가 경쟁 상황으로
   전이되지 않는다는 뜻이고, 그것도 결과다.
2. **모델 판별** — 이 5장에 대해 모델이 서로 다른 µM을 내놓는가. ← **본전**

## 7. 농도 헤드 물리 사전학습 (§6이 통과한 뒤)

조성 헤드는 이미 `simulate_mixtures`로 사전학습한다(`dl_model.py:358, 363`) — sweat 논문의
Monte Carlo 증강과 같은 발상, 같은 규모(5,000 vs 4,000). **그런데 농도 헤드(`make_conc_net`)는
사전학습을 쓰지 않는다.** 연결하면 되고, 근거가 있다:

`simulate_mixtures`가 **gain을 0.7–1.4로 흔든다**(`gain_lo/gain_hi`). 여기에 농도 헤드를
학습시키면 **모델이 gain으로 농도를 읽을 수 없게 강제되고**, 남는 길은 모양(shape)뿐이다.
모양은 물질마다 포화 지점이 달라 총량 정보를 담는다.

> **이것이 sweat 논문의 L2 정규화와 같은 전략이다.** 그쪽은 명시적으로 크기를 버렸고,
> 여기서는 gain jitter로 암묵적으로 버리게 만드는 셈이다. 코드는 이미 있다.

> ⚠️ **§6 없이는 붙여도 의미가 없다.** 34맵으로는 성공 여부를 판별할 수 없기 때문
> (농도 분산의 89%가 조성). 순서를 지킬 것.

**후처리(예측값 편향 보정)** 도 가능하다 — 계통 과소평가(DQ 0.23× / TBZ 0.25× / THI 0.48×)에
유효하다. 단 **fold 안에서 적합할 것.** 세션 초반의 "라벨범위 제약"이 정확히 이 함정이었다
(0.49 → 0.37 dec 개선이 사실은 모델에게 답의 위치를 알려준 결과).
