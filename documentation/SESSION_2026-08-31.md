## 3. TB24 µM 폭주 — 원장 마감

원인: **TBZ 1270 밴드가 TBZ 24 µM에서 ~6배 자체억제** (진단 T_i=Ccal_i/ratio_i: TB24 전 셀 T_TBZ 5–13 vs 30–100). 조성은 무사 → recovery 정상, µM만 지수 residual에서 폭주. 터지는 셀은 실행마다 다름(배포 6:24:6=93 µM, 통합 12:24:12=58 µM). **실패한 해법 8종**: Δ클립(binary 파괴)·3-seed 앙상블·TBZ 보조밴드·\|Δ\|플래그(ρ 0.05)·seed분산(ρ 0.18)·ratio-앵커(w2× 55%)·총량-residual(58.9%)·억제플래그(ρ −0.18). **남은 처방 = TB24 계열 반복측정** (캠페인 1순위 셀 확정).

## 4. "0을 0이라 말하기" — Presence 헤드 (실험 없이 해결)

- 근본 원인: softmax·지수 보정은 0 불가 + 부재의 겉보기 신호가 파트너 맥락 함수(고농도 부재 4.4% > 저농도 실존 1.2%) → 고정 문턱 원리적 불가.
- 열쇠: **검량 단일맵 = "파트너 있는 0"의 실측**. 바닥값 곡선 확정(`14_absence_floor_curves.csv`) — 오염 경로는 약한 DQ 파트너뿐(잉크 cosine 0.73). ⚠ 바닥값은 반드시 배경(BLK/INK) 템플릿 포함으로 계산(없으면 26–36%로 과대).
- **성분별 로지스틱 presence 헤드** (feature: 배경-인지 NNLS·마커밴드·총신호 — 누출 없음, 124맵): grouped 5-fold **AUC THI 0.997 / TBZ 0.940 / DQ 0.910**, 저농도 0의 Detected 오보 0/70, 8:1 소수의 거짓 ND 1/48.
- **배포 통합 완료**: `<dlm>.presence.json` 사이드카 자동 장착(load_model), apply_recovery가 성분별 `Detected / Indeterminate / ND` 보고. 데모: DQ3-TB3-TH24 → THI Detected(1.00)·3 µM 소수 Indeterminate. 문서: `PRESENCE_HEAD_2026-08-31.md`.
- 저농도 binary 측정은 이제 설계 필수 → **검증용**으로 강등.
