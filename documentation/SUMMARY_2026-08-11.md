64조건 완전격자 확보 이후의 결과·진단·수정 전부. 숫자는 모두 **조건 단위 held-out**이다.

## 0. 한 문단 요약

성분당 3–24 µM 구간에서 **조성은 잘 복원되고(64조건 격자 12.9%, 성분별 편향 ±1%p 이내), 농도는 2배 이내 74–83%의 준정량 수준**이다. 채택 구성은 `blank + sips`(§7). 정확도의 남은 몫은 대부분 액적 사이 산포(1.2–1.5배)라 알고리즘으로 줄일 수 없다. DQ만 저농도 정량이 어려운데, 이는 경쟁적 배제가 아니라 **DQ 고유의 불균일 흡착**(신호–농도 지수 0.52 vs 1.04–1.09) 때문이다.

## 2. 조성 — 잘 된다

### 조건 수 효과

같은 32조건에서 학습 데이터만 늘려 채점 (사과 대 사과, **둘 다 `base` 구성**):

```
35조건 학습   평균 12.2%   중앙 11.3%
65조건 학습   평균 10.7%   중앙  9.6%     (-1.5%p · 개선 24 / 악화 8)
```

**중앙값 9.6% = 반복산포 하한.** 절반의 조건이 측정 한계에 도달했다.

> ⚠ 이 비교는 **`base` 구성에서만 성립한다.** 채택 구성 `blank+sips` 로 같은 32조건을
> 채점하면 13.7% 다 — 그 구성은 저농도(DQ 3·6 µM)를 벌고 고농도(DQ 24 µM)를 잃기
> 때문이다(§7). **"조건을 늘려 12.2 → 10.7%" 와 "채택 구성은 blank+sips" 를 한 문단에
> 같이 쓰면 안 된다.** 조건 수 효과를 말할 때는 구성을 고정했다고 밝힐 것.

전체 65조건 평균은 13.6%인데, 새로 들어온 DQ 3·6 µM 이 어렵기 때문이다.
**평균끼리("12.9% → 13.6%") 비교하면 안 된다** — 평가 대상이 달라졌다.

### 어디가 어려운가

```
채택 blank+sips   DQ  3 µM 14.4%   6 µM  9.3%   12 µM 12.2%   24 µM 15.7%
참고 base         DQ  3 µM 18.6%   6 µM 13.5%   12 µM 12.5%   24 µM  9.8%
참고 blank2       DQ  3 µM 16.2%   6 µM 10.6%   12 µM 10.9%   24 µM 11.8%
```

DQ 3 µM 은 혼합 LOD(2.90 µM) 바로 위다. 별도 표기 대상.
구성마다 **어느 농도를 벌고 어느 농도를 잃는지가 다르다** — §7 참조.

### 성분별 (64조건)

```
채택 구성 blank+sips        참고: base
        기울기   R²    편향          기울기   R²    편향
DQ       0.58   0.65   -0.8%p        0.60   0.69   +6.7%p
TBZ      0.66   0.72   +0.6%p        0.62   0.74   -4.8%p
THI      0.65   0.75   +0.2%p        0.56   0.76   -2.0%p
```

**채택 구성에서는 세 성분 편향이 모두 ±1%p 안이고 0과 통계적으로 구분되지 않는다**
(p = 0.56 / 0.61 / 0.88). base 의 DQ +6.7%p 는 잉크가 DQ 로 잘못 실린 결과였다(§6).

기울기 <1 은 **눌림(shrinkage)** 이다. R² 는 32조건 대비 전부 올랐다(참값 산포가 넓어져 천장이 올라감).

### R² 의 천장은 반복 산포가 정한다

반복 SD 는 DQ 4.1 · TBZ 4.8 · THI 4.9 %p 인데 조건 간 참값 산포는 15.5%p 뿐이고,
32조건 중 29개가 맵 1장이라 그 점 하나가 반복 산포를 그대로 뒤집어쓴다.

```
R² 상한   DQ 0.80 · TBZ 0.83 · THI 0.73
실측      0.45 / 0.72 / 0.60  (32조건 기준)  →  TBZ·THI 는 이미 상한의 82–86%
```

**"R² 가 낮다 → 모델이 나쁘다"로 읽으면 안 된다.** 올리려면 ① 조건당 반복 3회
(상한 0.83→0.94) ② 극단 조성 추가, 둘뿐이다.

## 2-1. 고농도까지 넓혀서 — 세 블록으로 나눠 본다

`retrain_all.py 120 4 blank`. 고농도 32맵도 **조성 키로 묶어 fold 에 넣어** held-out 으로
채점했다(전에는 학습에만 들어갔다). 블록을 분리하는 이유는 문제의 성격이 다르기 때문이다 —
고농도 32맵 중 24맵이 **이원**(한 성분이 진짜 0이라 쉽다)이고, 삼원 7맵은 성분당 1000 µM 라
THI 가 표면을 독점하는 구간이다. 한 숫자로 합치면 평균이 "문제가 쉬워서" 움직인다.

```
저농도 65조건 (삼원, 3–24 µM)   평균 12.6%   중앙 11.4%
고농도 이원 24조건               평균 14.8%   중앙 12.3%
고농도 삼원  7조건               평균 30.5%   중앙 34.0%
```

> 저농도 12.6% 는 §7 의 채택값(12.9%)과 다르다. 이 실행은 고농도 시험 조건을 학습에서
> 빼므로 **학습셋이 달라졌다.** 두 숫자를 나란히 비교하지 말 것.

### 소수 성분 검출 계열 — 두 성분 1000 µM 고정, 세 번째만 내림

묻힌 성분의 참 분율이 33.3% → 4.8% → 0.5% 로 내려가고, 세 성분에 대칭으로 설계돼 있다.

| 조성 (µM) | 묻힌 성분 | 참 분율 | 예측 | 회수 | 조성오차 |
|---|---|---:|---:|---:|---:|
| 1000/1000/10 | THI | 0.5% | 0.8% | 159% | 18.0% |
| 1000/10/1000 | TBZ | 0.5% | 0.9% | 177% | 38.0% |
| **10/1000/1000** | **DQ** | 0.5% | **8.9%** | **1792%** | 39.2% |
| 1000/1000/100 | THI | 4.8% | 5.5% | 116% | 17.9% |
| 1000/100/1000 | TBZ | 4.8% | 1.0% | 22% | 34.0% |
| 100/1000/1000 | DQ | 4.8% | 6.6% | 138% | 36.4% |
| 1000/1000/1000 | — | 33.3% | DQ 62.0% | 186% | 30.3% |

**① 묻힌 성분 자체는 잡힌다** — THI 0.5% → 0.8%, TBZ 0.5% → 0.9%. 회수율은 159–177% 지만
절대값으로는 0.4%p 차이라 "미량 존재"를 맞힌 것이다. **정량이 아니라 검출**로 쓸 것.

**② DQ 만 다르다** — 0.5% 를 8.9% 로 읽는다(회수 1792%). 등몰 1000 µM 에서도 DQ 를 62% 로
본다. **DQ 바닥값이 고농도에서도 그대로 작동한다** — §5·§6 에서 본 것과 같은 현상이고,
여기서는 참값이 0.5% 라 비율이 폭발한다. 저농도·고농도 양쪽에서 같은 결론이 나온 셈이다.

**③ 지배 두 성분의 비율을 못 가린다** — 조성 오차가 30–39% 인 이유는 묻힌 성분이 아니라
1000/1000 두 성분을 50:50 으로 나누지 못하기 때문이다. THI 쪽으로 쏠린다(§5 의 THI 표면 독점).

### 보고 문구

> 성분당 1000 µM 수준에서는 THI 가 표면을 독점해 조성 판독이 무너진다(오차 30.5%).
> 이는 알고리즘 한계가 아니라 흡착 경쟁의 결과이며, 작업 구간을 3–24 µM 으로 한정한 근거다.
> 한편 그 구간에서도 **미량 성분의 검출**은 가능하다 — THI·TBZ 는 조성 0.5% 까지 잡힌다.

## 3. 농도 — 준정량

전처리 clip-only, 모델 `s = g_m · r_i · C`, 조건 단위 LOO.

```
전체 2배 이내   74%          총 농도 2배 이내   89%
성분별          DQ 56% · TBZ 79% · THI 86%
DQ 3 µM 제외    76%          (DQ 만 보면 65%)
```

농도 수준별 2배 이내:

```
          3 µM   6 µM   12 µM   24 µM
   DQ      19%    73%     52%     70%
  TBZ      50%    88%     82%     89%
  THI      81%    86%     89%     90%
```

**보고 기준**: 성분당 6 µM 이상에서 2배 이내 76%, 총 농도 89%.
DQ 는 3 µM 조건에서 농도를 보고하지 않고 `< LOD` 로 둔다.

### 무엇이라 부를 것인가

```
SANTE   회수율 70–120% · RSD ≤ 20%
2배 이내 = 50–200%  →  SANTE 보다 4배 느슨
```

**정량(quantitative determination)이 아니라 준정량 스크리닝(semi-quantitative
screening)으로 쓴다.** 단, 액적 산포가 1.2–1.5배라 단일 액적으로는 2배가 물리적
하한에 가깝다 — 방법이 부정확한 게 아니라 액적 하나의 한계다.

### 응답계수가 불안정하다

```
35조건   DQ 1.00 : TBZ 2.01 : THI 1.69
64조건   DQ 1.00 : TBZ 1.25 : THI 1.01
```

성분 상수여야 하는데 1.6배 넘게 움직였다. `rf_calib.py` 의 세 추정 경로가 3–8배로
흩어진 것과 같은 문제. **단일 상수 응답계수로 고정하는 판독의 한계**다.

## 4. 산포의 단위는 액적이다

같은 조성 반복맵으로 분산을 분해:

```
성분   픽셀 SD    n=100 중앙값 표준오차    액적 SD
DQ     3.51배         1.13배              1.53배
TBZ    1.65배         1.05배              1.47배
THI    1.38배         1.03배              1.19배
```

**액적 SD 가 n=100 표준오차보다 5–34배 크다.** 픽셀을 1000개 찍어도 안 줄어든다.
잉크 기판이라 기판 통제도 불가. 정밀도를 올리는 유일한 길은 **조건당 액적 수**다(√n).

예외 두 곳: `12/12/48`·`6/6/24` 의 DQ 만 픽셀 SD 가 액적 SD 보다 크다 — THI 가 많은
조건에서 DQ 가 픽셀 단위로 검출되다 말다 한다.

## 5. 흡착 물리

### 단일성분 등온선 (검량 9점, 0.1–1000 µM)

| 성분 | K (M⁻¹) | 1/K (µM) | gA | m (Sips) | 1/n (Freundlich) | R² L / S / F |
|---|---:|---:|---:|---:|---:|---|
| DQ | 7.05×10³ | 141.8 | 1.25×10⁵ | 0.656 | 0.352 | 0.889 / 0.916 / **0.978** |
| TBZ | 3.39×10⁴ | 29.5 | 1.24×10⁵ | 0.721 | 0.253 | 0.948 / **0.959** / 0.942 |
| THI | 3.10×10⁴ | 32.2 | 9.48×10⁴ | 0.967 | 0.278 | **0.985** / 0.985 / 0.897 |

Sips 의 K 는 Langmuir 값으로 고정하고 m 만 자유롭게 뒀다. 셋 다 자유로 두면 DQ 가
K=2×10⁻⁸, gA=7×10⁸ 로 퇴화해 경쟁 분모에서 무의미해진다.

**최적 모델이 성분마다 다르다** — DQ 는 Freundlich, THI 는 Langmuir(m≈0.97), TBZ 는
중간. 하나의 닫힌 등온선으로 셋을 동시에 기술할 수 없다.

### K 의 신뢰구간 — TBZ vs THI 는 못 가린다

잔차 부트스트랩 2000회:

```
DQ    7.05e3   95% CI  4.54e3 – 1.60e4
TBZ   3.39e4   95% CI  2.51e4 – 6.32e4
THI   3.10e4   95% CI  2.33e4 – 4.44e4
TBZ > THI 인 비율 76%   →  순서 결론 불가
```

**말할 수 있는 것은 `DQ ≪ TBZ ≈ THI` 뿐이다.** "TBZ 의 흡착이 가장 좋다"고 쓰면
신뢰구간과 혼합물 실측 양쪽에서 반박당한다.

### DQ 는 왜 다른가 — 매몰이 아니다

잉크를 기저에서 분리한 뒤 `log B_i ~ log C_i + 경쟁농도` 회귀:

```
        자기 농도 지수    경쟁 계수 (1/µM)
DQ         0.518        TBZ -0.0001  THI -0.0004     ← 경쟁 영향 사실상 0
TBZ        1.087        DQ  +0.0054  THI -0.0166     ← 여기만 뚜렷한 억제
THI        1.036        DQ  +0.0038  TBZ +0.0044
```

**DQ 를 누르는 것은 없다.** 오히려 눌리는 쪽은 TBZ(THI 에 의해)다. DQ 의 낮은 지수는
경쟁자가 없는 단일성분 검량에서도 같다(농도 1만 배에 신호 9.3배, THI 는 25배).

기전 해석(측정한 것이 아니라 해석): THI 는 dithiocarbamate, TBZ 는 thiazole S +
benzimidazole N 으로 Ag 에 화학흡착하는 반면, DQ 는 연성 donor 가 없는 이가 양이온이라
정전기적 물리흡착에 의존한다. 화학흡착은 자리가 균일하고(m≈1) 정전기 흡착은 표면 전하
분포를 따라 결합에너지가 퍼진다(m=0.66).

**→ DQ 의 저농도 정량 한계는 알고리즘이 아니라 흡착 물리에서 온다. "경쟁에 밀려서"라고
쓰면 단일성분에서 왜 같은지 답을 못 한다.**

### 고농도에서는 THI 가 표면을 덮는다

등몰 삼원 시리즈 (참 조성은 언제나 33/33/33), NNLS 표면 조성:

```
성분당 10 µM    30.3 / 23.1 / 46.6
성분당 33 µM    17.8 / 34.1 / 48.1
성분당 100 µM    0.0 /  0.0 / 100.0      ← 순수 THI 와 코사인 0.99, 재구성 R² 0.98
성분당 333 µM    0.0 /  0.0 / 100.0
```

관측은 단단하다. **다만 Langmuir·Freundlich 어느 쪽도 이걸 예측하지 못한다**(둘 다
100 µM 에서 약 30/40/30 을 예측). 등온선으로 설명하려 들지 말고 **관측 사실로만** 쓴다.
이 시리즈의 용도는 "왜 3–24 µM 만 다루는가"의 근거 한 장이다.

**학습 구간 밖에서 MLP 를 쓰면 안 된다** — 같은 맵에서 MLP 는 DQ 를 46–52%라고 답한다.
표면에 DQ 신호가 0인데도. 조성 헤드가 softmax 라 "아무것도 없음"을 말할 수 없고,
조성 헤드에는 OOD 가드가 없다(µM 헤드에만 있음).

## 6. 진단: 잉크가 DQ 를 오염시킨다

`dataset.py:29  BLANK_ALIASES = {"blk","blank","background","bg","none","ink"}`
→ **INK·BLK 가 NNLS 템플릿에서 빠진다.** 그런데 잉크는 실제 주성분이다.

```
템플릿 코사인 (DQ 와)    INK 0.732  >  TBZ 0.664  >  THI 0.516  >  BLK 0.316
INK 계수 중앙값          15198  =  DQ 자신(7917)의 1.9배
BLK 계수 중앙값          0                              ← 기판 배경은 무죄
```

갈 곳 없는 잉크 몫을 가장 닮은 DQ 가 떠안는다:

```
기저 3성분   DQ 절편 = 중앙값의 98%  ·  R² 0.25  ·  농도 8배에 신호 1.7배
기저 5성분   DQ 절편 = 52%           ·  R² 0.48  ·  3.0배
```

단, **5성분 NNLS 로 그냥 바꾸는 건 답이 아니다** — 조성 오차가 15.9 → 17.9% 로 나빠지고
DQ 과소·THI 과대로 뒤집힌다. 잉크와 DQ 가 0.73 으로 닮아 선형 분해로는 못 가른다.

## 7. 시도한 처방 여섯 갈래 — 채택은 `blank + sips`

전부 물리 사전학습이 정상 실행된 상태 (§8 의 함정을 고친 뒤 재실행).

| 갈래 | blank | 잉크 | Sips | 평균 | 중앙 | vs base | DQ | TBZ | THI | \|편향\|합 | 기울기폭 |
|---|:---:|:---:|:---:|---:|---:|---:|---:|---:|---:|---:|---:|
| `base` | ✗ | ✗ | ✗ | 13.6% | 12.1% | — | +6.7 | −4.8 | −2.0 | 13.5 | 19.1 |
| `ink` | ✗ | ✅ | ✗ | 14.0% | 13.9% | +0.38±0.77 (p=0.62) | +1.9 | +3.9 | −5.8 | 11.5 | 21.2 |
| `sips` | ✗ | ✗ | ✅ | 12.7% | 12.9% | −0.86±0.67 (p=0.21) | +1.7 | −2.2 | +0.6 | 4.5 | 24.4 |
| `blank2` | ✅ | ✗ | ✗ | 12.4% | 11.9% | −1.21±0.56 (p=0.033) | +2.2 | −2.4 | +0.1 | 4.7 | 20.7 |
| **`blank+sips`** | ✅ | ✗ | ✅ | **12.9%** | **12.4%** | −0.71±0.78 (p=0.37) | **−0.8** | **+0.6** | **+0.2** | **1.7** | 23.4 |
| `all3` | ✅ | ✅ | ✅ | 14.6% | 13.8% | +0.99±0.91 (p=0.28) | +3.4 | +3.5 | −7.0 | 13.9 | 19.1 |

*단위 %p · 기울기폭 = DQ 3 µM 편향 − 24 µM 편향*

### 채택: `blank + sips`

```
retrain64.py 120 4 blank,sips     →  include_blank=True, sim_iso="sips_dq", 잉크 주입 없음
조성 65조건 12.9% · 중앙 12.4%
편향 DQ −0.8 · TBZ +0.6 · THI +0.2 %p   ← 셋 다 0과 구분 안 됨 (p 0.56 / 0.61 / 0.88)
```

**고른 이유는 편향이다.** 오차로는 `blank2`(12.4%)와 구분되지 않지만(+0.50±0.45, p=0.27),
편향은 명백히 갈린다 — DQ +2.25 → −0.83 %p, TBZ −2.37 → +0.64 %p, 둘 다 **p < 0.0001**.
정량을 주장하려면 계통 편향이 산포보다 치명적이다. 산포는 반복으로 줄지만 편향은 안 준다.
Sips 는 임의 튜닝이 아니라 **DQ 등온선이 실제로 Freundlich 를 선호한다**는 검량 근거가
따로 있다(§5).

### 대가: 저농도를 벌고 고농도를 잃는다

```
DQ 수준별 조성 오차 (%)        DQ 3    DQ 6   DQ 12   DQ 24   전체
  base                        18.6    13.5    12.5     9.8    13.6
  blank2                      16.2    10.6    10.9    11.8    12.4
  blank+sips (채택)           14.4     9.3    12.2    15.7    12.9

blank+sips − base    DQ 3  −4.2%p (p=0.003)   DQ 6  −4.2%p (p=0.000)
                     DQ 12 −0.3%p (p=0.80)    DQ 24 +5.9%p (p=0.001)
```

셋 다 유의하다. **편향이 0에 가까워진 것은 이 맞바꿈의 결과**이지 전반적 개선이 아니다.
`blank2` 는 DQ 수준별로 가장 고르므로(10.6–16.2%), 균형을 우선한다면 정당한 대안이다.

### 다 더하면 나빠진다

`all3` 은 14.6% 로 base 보다 못하고 편향도 13.9%p 로 되돌아간다. 잉크·Sips·blank 가
모두 "DQ 지분을 깎는" 같은 방향이라 과보정된다. 단독으로도 TBZ·THI 를 반대편으로 밀었던
`ink` 가 주범으로 보인다 — **채택 구성에 잉크 주입은 넣지 않는다.**

### DQ 기울기폭은 끝내 안 잡혔다

```
DQ 편향        3 µM    6 µM   12 µM   24 µM   폭
 base         +15.1   +10.3    +5.7    -4.0   19.1
 ink          +11.6    +5.2    +0.5    -9.6   21.2
 sips         +12.4    +4.1    +2.2   -12.0   24.4
 blank2       +11.6    +5.4    +1.2    -9.1   20.7
 blank+sips    (평균 편향은 0, 기울기는 남음)          23.4
 all3         +10.2    +8.0    +4.4    -8.9   19.1
```

여섯 갈래가 19–24%p 로 전부 비슷하다. 저농도 과대가 줄면 고농도 과소가 그만큼 깊어질 뿐,
**농도 의존성 자체는 어느 처방도 못 건드린다.** §5 의 진단(DQ 신호–농도 지수 0.52)과
일치하며, 여섯 번 시도해 여섯 번 같은 결론이 나왔으므로 **학습으로 넘을 수 없는 물리**로
본다.

## 8. 발견한 함정 · 적용한 수정

### 함정 (둘 다 조용히 일어난다)

1. **`include_blank=True` 가 물리 사전학습을 껐다.** `dl_model.py:332` 가 `subs` 에
   blank 를 붙여 4개로 만드는데 게이트가 `if len(dil) == len(subs)` 이고 검량 CSV 에는
   3성분뿐이라 3 ≠ 4 → 통째로 건너뜀. 로그에도 안 남았다.
   → 첫 `blank`·`both` 실험은 "blank 효과"가 아니라 "사전학습 없음 + blank" 였고,
   둘이 소수점까지 동일했던 이유도 이것이다(잉크는 사전학습에만 들어간다).
   **수정 완료** — 분석물 개수로 게이트를 비교하고 사전학습 라벨에 blank 열(0)을 덧붙인다.
   고친 뒤 재실행하니 13.7% → **12.4%** 로, 함정이 실제로 성능을 깎고 있었다.
2. **앱의 분할 단위가 조성이 아니라 맵이었다.** 반복맵이 train/test 로 갈렸다.
   `kfold_stability` 는 basename 정렬 후 스트라이드라 형제 반복맵이 **반드시** 다른
   fold 로 흩어졌다. **수정 완료.**

### 적용한 수정

```
dl_model.py       분할 키를 조성 튜플로 (풀링 키는 맵 그대로 — 둘을 분리)
                  농도 헤드는 조성+절대농도를 키로
                  _nuisance_refs() 추가 — INK·BLK 템플릿
dl_quantify.py    simulate_mixtures(nuisance=..., iso_m=...) — 기본값은 기존 동작 불변
competitive.py    coverages/forward_spectrum 에 Sips 지수 m (m=None 이면 Langmuir)
calibration.py    fit_sips(fix_K=True)
```

검증: 6맵(중복 조성 포함) → fold 4 = 고유 조성 수, 보고 6행 = 맵 수.
MLP+농도 헤드 7맵/5조건 → 조성·µM 모두 `level=condition`, `n_maps` 7 유지.
`nuisance=None`, `iso_m=None` 은 예전 결과와 bit-identical.

### 써도 되는 것

```
조성   64조건 격자, leave-one-condition-out, 구성 `blank+sips`.
       65조건 평균 12.9% · 중앙 12.4% · 성분별 편향 ±1%p 이내(0과 구분 안 됨).
       조건 수 효과를 말할 때는 구성을 base 로 고정: 같은 32조건에서 12.2% → 10.7%,
       중앙 9.6% 로 반복산포 하한 도달. (구성과 조건 수를 한 문장에 섞지 말 것)
농도   성분당 6 µM 이상에서 2배 이내 76%, 총 농도 89%.  준정량 스크리닝.
DQ     연성 donor 없는 이가 양이온이라 흡착이 약하고 불균일하다(K 4–5배 낮음,
       신호–농도 지수 0.52 vs 1.04–1.09).  경쟁 억제는 유의하지 않으므로
       경쟁적 배제가 아니라 물질 고유 특성.  TBZ·THI 는 같은 구간에서 정량 가능.

DL근거 닫힌 등온선이 성분마다 갈리고(DQ Freundlich, THI Langmuir), 혼합물 거동은
       어느 쪽으로도 예측되지 않으며, 선형 분해도 부족하다(NNLS 18.4% vs MLP 10.7%).
```

### 쓰면 안 되는 것

```
✗  "12.9% → 13.6%"  평균끼리 비교 — 조건 구성이 달라 의미 없음
✗  "조건을 늘려 12.2 → 10.7%" 를 채택 구성(blank+sips)과 같이 쓰기 — 그 구성에서는
   같은 32조건이 13.7% 다. 조건 수 효과는 base 로 고정해서 말할 것
✗  "TBZ 의 흡착이 가장 좋다"  — K 신뢰구간이 겹침(TBZ>THI 확률 76%)
✗  "DQ 가 경쟁에 밀려서"  — 경쟁 계수 ~0, 단일성분에서도 같은 현상
✗  "111 µM THI 지배를 Langmuir 로 설명"  — K 는 TBZ 가 최대라 정반대를 예측
✗  "정량(quantitative)"  — 2배 이내는 SANTE 보다 4배 느슨. 준정량이라 쓸 것
✗  학습 구간(3–24 µM) 밖 MLP 출력  — DQ 0 인데 46% 를 답함
```
