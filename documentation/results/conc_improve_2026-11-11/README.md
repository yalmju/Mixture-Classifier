# 농도 판독을 더 올릴 수 있는가 (2026-11-11 탐색)

대상은 논문 모델의 농도 단계(맵 평균 스펙트럼 ÷ 2137 → PLS 8, 64 조건 2배 이내 94.3 %, 대조 상수 50.0 %).
모델 파일 · 본문 문서는 건드리지 않았다. 아래 수치는 따로 적지 않으면 최종 조제 64 조건, 조건 묶음 5-fold × 20 회 held-out 이다.

## 결론

1. **남은 오차는 식이 아니라 액적(맵)에 있다.** 한 맵의 세 성분 오차는 서로 거의 무관하고(상관 −0.17 · +0.23 · +0.05),
   잉크 세기 · 배경 · 픽셀 불균일 · 측정 순서 어느 것과도 상관이 없으며(|r| ≤ 0.22), 같은 조건을 다시 조제해 찍으면
   오차가 바뀐다(두 맵 오차의 상관 +0.14, 옛 조제 12 쌍). 스펙트럼 안에 이 오차를 알려 주는 정보가 없다.
2. **한 맵 안에서 얻을 수 있는 것은 한 가지뿐: 농도 단계 입력을 지문 영역(500–2000 cm⁻¹)으로 자르기.**
   2배 이내 94.3 → 95.8 %, 1.5배 72.9 → 76.6 %, RMSE 0.161 → 0.153 dex, 기울기 0.76 → 0.80, 세 성분 모두 2배 54 → 57/64
   (모델 기록과 같은 방식; 대조 50.0 %). 1500–2050 어디서 잘라도 같고(넓은 봉우리), 고르기를 학습 쪽 안에서 해도 유지되며
   (중첩 CV 100/100 fold 가 이쪽을 고름). ~~다른 조제(08-08)에서도 같은 방향~~ — 독립 확인이 아니다(아래 "정정"). 잘려 나가는 것은 나눗셈에 이미 쓴
   잉크 밴드와 그 위의 빈 구간이다.
3. **나머지 45 가지 변형은 이득이 없거나, 고르기를 안에 넣으면 사라진다.** 세제곱근 변환 · PLS 12 · 밝은 절반 픽셀 · 밴드 식과
   평균은 따로 보면 95.8–96.3 % 까지 가지만 전부 후보로 넣은 중첩 CV 는 95.4 % · RMSE 0.154 — 범위 자르기 하나와 같다.
4. **학습 혼합물을 더 재도 조금만 는다.** 학습 곡선 RMSE² = a + b/n 의 바닥 0.140 dex; 64 → 128 조건이면 0.159 → 0.150.
5. **크게 줄이는 방법은 같은 표면을 한 번 더 써서 읽는 것뿐이다(희석 아님).** 재조제 12 쌍: 한 맵 0.144 dex →
   두 맵 판독의 기하평균 0.112 dex(부트스트랩 90 % 구간 0.093–0.130), 2배 이내 94.4 → 100 %(36/36). 제곱오차의 78 % 가
   다시 찍으면 바뀌는 부분. 쌍의 한쪽은 최종 격자 맵 그 자체(DQ 3 µM 줄, TBZ · THI 3–24 µM), 다른 쪽은 용액부터 따로 만든
   `DQ9-sus`(TB/TH 라벨을 바로잡은 12 맵)다 — 아래 "정정". 재조제 쪽이 라벨을 바로잡은 세트라는 점은 남는다.

## 읽을 때 주의

- `e1` 의 "세 성분 공통 34.9 %" 는 공통 원인이 있다는 뜻이 아니다. 세 오차가 서로 독립이어도 평균 성분은 1/3 이 된다 —
  성분 간 상관이 0 근처라는 것이 실제 내용이다(잉크 밴드로 나누면서 공통 부분은 이미 빠졌다).
- **정정(11-11 저녁).** 이 폴더에서 "옛 조제 / 다른 조제(08-08), 9–72 µM" 라고 적은 `Baseline260808` 격자는
  **최종 격자(`260814_mixture_final`)와 같은 측정이다** — 64 조건 스펙트럼이 완전히 같고, 파일명만 섞기 전 원액 농도
  (9 · 18 · 36 · 72 µM = 최종 3 · 6 · 12 · 24 µM × 3, `PLAN_64conditions.md`)로 적혀 있다. 따라서
  ① `e6` ③ 의 "다른 조제에서도 같은 방향" 은 독립 확인이 아니다(같은 자료를 조건 하나씩 빼기로 다시 본 것),
  ② 96.9 % 는 72 µM 까지 읽힌다는 근거가 아니다(실제 농도는 3–24 µM), ③ `e5` 의 재조제 12 쌍은 "옛 조제" 가 아니라
  최종 격자 조건(DQ 3 µM 줄)과 그 재조제(`DQ9-sus-relabeled`)의 쌍이다. `e5` · `e6` 의 dex · 배수 수치는 라벨 단위와
  무관해 그대로지만, 그 안의 µM 표기(9–72)는 원액 기준이다.
- 눌림(기울기 < 1)은 위의 산포가 있는 한 회귀식에서 사라지지 않는다. 범위 자르기로 0.76 → 0.80, 그 이상은 산포가 줄어야 한다.
- **채택(11-11, 사용자 "자르자").** 논문 모델의 농도 단계를 500–2000 cm⁻¹ 로 다시 맞췄다(`train_paper_pls.py` 의
  `CONC_SPECTRUM_CM`, 모델의 `uM["spectrum_range_cm"]`). 저장 모델에서 다시 계산한 수치(`conc_head_2026-11-10/paper_numbers.txt`):
  64 조건 2배 이내 95.8 % (184/192) · 1.5배 76.6 % · 중앙 1.27× · RMSE 0.153 dex · 기울기 0.80 · 셋 다 57/64 (대조 상수 50.0 %),
  성분별 DQ 92.2 · TBZ 96.9 · THI 98.4 %, 시험 12맵 97.2 % · 83.3 % · 1.18×. 조성 단계 기록은 그대로(12.6 / 10.9 %p).
  500–2500 판은 `…_spec2500.dlm` · `paper_numbers_spec2500.txt` 로 남겼다. 위 "대상" 줄과 표의 94.3 % 는 그 판의 값이다.
