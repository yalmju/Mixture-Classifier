# 이원 비율 계열 × DFT — 경쟁 흡착 눈금의 실험 검증 (2026-11-09)

고농도 `high` 세트의 이원 맵 27장(한 성분 0, 쌍마다 9비율 · 100:1~1:100)에서
**용액 비율 vs NNLS 신호 조성** 응답곡선을 뽑아, DFT(`sers_simulation_code/FINAL/
DFT_results_summary.md`)의 경쟁 흡착 서열과 대조했다.

만든 것: `scripts/binary_response.py` → `scripts/binary_response.{npz,png}`.
판독은 `tert_nnls.py`·`export_nnls.py` 와 같은 경로(맵평균 한 줄 → `surface_composition`)다.

## 왜 duet net 이 아니라 NNLS 로 재는가

- DFT 가 예측하는 것은 **표면(신호) 조성**이다. duet net 은 용액 조성을 되돌리도록
  학습돼 있어, 잘 작동할수록 경쟁 흡착의 흔적을 지운다 — 재려는 것을 지우는 도구다.
- duet net 은 Sips 등온선으로 **물리 사전학습**을 받는다. 그걸로 흡착 물리를 검증하면
  순환이다. NNLS 는 학습·사전확률이 없는 선형 투영이라, 곡선의 휘어짐 전부를
  물리(흡착 경쟁 × 분자당 단면적)에 귀속할 수 있다.
- 서사(FINDINGS §5)와도 일치한다: NNLS = 신호 판독기, duet net = 그 위의 역변환.

## 결과 — 교차점 x0 (신호가 50:50 이 되는 용액 비율, log10)

로지스틱 f_A = 1/(1+exp(−(x−x0)/w)), x = log10([A]/[B]). 눈금이 안 휘었으면 x0 = 0.

```
THI/DQ    x0 = −1.05   w = 0.35   용액 DQ:THI = 11.3:1 이어야 신호 50:50
THI/TBZ   x0 = −0.71   w = 0.26   용액 TBZ:THI =  5.1:1 이어야 신호 50:50
DQ/TBZ    x0 = +0.30   w = 1.29   ← 적합 신뢰 낮음 (아래)
```

**삼각 닫힘**: 성분별 "신호 승률" 스케일 a 가 존재한다면 δ(THI/TBZ) = δ(THI/DQ)+δ(DQ/TBZ).
실측 1.05 + (−0.30) = 0.75 vs 직접 적합 0.71 — **0.04 dex 안에서 닫힌다.**
세 곡선이 서로 독립인데 하나의 성분별 스케일로 설명된다 = 평형 경쟁 그림과 자기일관.

## DFT 와의 대응 (순서·부호만 — DFT §10 의 원칙대로 eV 환산은 하지 않는다)

| 관측 | DFT 해석 |
|---|---|
| THI 가 두 쌍 모두에서 이김 (x0 −1.05 · −0.71) | 흡착 서열 THI 최강 (THI←TBZ −2.2~−4.0 eV · 포화에서 THI←DQ −0.94) |
| THI 는 **분자당 라만 신호가 가장 작은데도** 이김 (검량 기울기 TBZ ≫ DQ > THI) | 신호 = 피복률 × 단면적 — 단면적 열세를 뒤집는 건 흡착 우세뿐. 흡착 없이는 설명 불가 |
| DQ vs TBZ 는 **TBZ 쪽으로** 기움 (x0 +0.30) — 흡착 서열(DQ ≫ TBZ)과 반대 | 단면적이 이기는 유일한 쌍: TBZ 의 분자당 신호가 흡착 열세를 상쇄. Fig 3a 기울기와 합성하면 부호가 맞다 |
| 전이폭 w ≈ 0.3 dex (THI 쌍) — 급격한 스위치 | 자리 경쟁(포화 표면에서 승자독식)과 정합. 비경쟁 선형 혼합이면 w = 0.43(순수 비율 희석)보다 완만할 수 없음* |

*w 해석은 잠정 — 선형 기준선의 w 를 같은 눈금으로 유도해 붙일 것.

## 한계 (캡션에 들어가야 할 것)

1. **총농도가 비율 축과 얽혀 있다** (200–1000 µM, 그림의 색). 곡선은 '비율+총량'의
   합성 응답이다. 순수 비율 응답이라 주장하지 말 것.
2. **DQ–TBZ 쌍은 이 데이터로 해소 안 된다** — w = 1.29, 비단조(예: DQ:TBZ 3:1 에서
   f_DQ 0.83 인데 5:1 에서 0.27). 맵당 1장이라 액적 산포(조성 RMSE 0.130,
   `sers-droplet-reproducibility`)가 그대로 들어온다. x0 +0.30 은 "TBZ 쪽으로 기운다"
   는 부호까지만 쓰고 크기는 쓰지 말 것.
3. 판독은 맵평균 NNLS 한 줄 — 픽셀 분포·공간 불균일은 안 들어갔다.
4. DFT 는 0 K·암시용매라 **순서와 부호만** 대조한다. x0(dex)를 eV 로 환산하지 않는다.

## 합동 척도와 그 한계 (`--merge`, 2026-11-09)

27 이원 점 전부를 성분별 세기 하나로 적합하면 **a_DQ −0.28 · a_TBZ 0 · a_THI +0.92
(dex)**, 쌍별 x0 이동만으로 세 쌍이 **마스터 곡선 하나**에 수렴한다
(`binary_response_merged.png` 왼쪽). 단 공유 폭 w=0.72 는 DQ–TBZ 산포가 끌어올린
값이다(THI 쌍 단독 0.26–0.35) — 곡선을 보여줄 땐 THI 쌍 기준으로 긋고 DQ–TBZ 는
점만 둘 것.

**비율-만(share) 모델은 삼원·등몰에서 체계적으로 실패한다** (RMSE 0.186 / 0.207):

- 실측 THI 독점(1.00)이 예측(0.68–0.83)보다 완전하다 — 포화가 takeover 를 격화.
- 등몰 1:1:1 실측은 총농도에 따라 변하는데(10 µM 33/21/46 → ≥100 µM 0/0/100)
  비율-만 모델은 상수(0.13/0.19/0.68)다.
- `DQ333-TB333-TH3`(THI 1/100): 실측 DQ 0.65 / TBZ 0.29 — binary x0(+0.30,
  TBZ 기움)과 **반대 부호**. DQ–TBZ 미해소의 추가 근거.

**해석**: 경쟁은 (비율) × (총농도) 2축이다. 비율 축에서는 성분별 세기 하나로 닫히고
(삼각 닫힘), 총농도 축에서는 포화가 winner-take-all 을 격화한다 — DFT 의 "자리가
모자라면 THI 독점"과 정확히 같은 그림이고, "곡선은 비율+총량의 합성 응답"이라는
캡션 경고의 정량 확인이다.

**Fig 3c 권고**: (이원 응답곡선 = 비율 축) + (등몰·1:1:x 희석 시리즈 = 총농도 축)
두 패널로 가고, 합동 share 모델은 SI 로("비율만으로는 포화 거동을 설명 못 한다").

## 반복 조제 7장 추가 — 전이 구간은 조제 간 재현되지 않는다 (2026-11-09)

최종 카탈로그 밖 별도 조제 7장(md5 로 확인; 명명 규약은 binary↔final md5 쌍으로
해독 — `TBZ100DQ1` = TBZ:DQ 100:1)을 곡선에 추가했다. 결과:

```
레일(|비율|=100): 재현됨      THI/DQ 1.00↔0.985 · DQ/TBZ 0.965↔0.839 (≤0.13)
전이 구간:        재현 안 됨   TBZ:THI 3:1 → {0.54, 0.76, 1.00} (3조제)
                              THI:TBZ 1:10 → {0.085, 1.000}
                              DQ:TBZ 1:10 → {0.221, 0.964}
```

변동 폭 0.3–0.9 는 액적 산포(0.13)를 한참 넘는 **조제/배치 수준**이다
(픽셀 선택 분석의 "불확도 99.5%가 액적/배치"와 정합). 재적합하면
x0 −0.95 / −1.13 / −0.14, w 0.51 / 0.51 / 1.75 — w 팽창이 곧 배치 산포다.
삼각 닫힘은 재적합에서도 0.04 dex 로 유지된다.

**주장 수위 (최종)** — 조제 전부에서 성립하는 것만 쓴다:

- 용액 1:1 에서 신호는 THI 로 쏠린다 (96–98%).
- THI 는 3배 열세(1:3)에서도 신호 우위·동률 이상을 유지한다 (3/3 조제).
- 교차점 변위의 **부호와 자릿수**(승자 쪽으로 ~1 dex): 유지.
- 교차점의 정밀값(x0±w)은 조제 간 변동으로 확정 불가 — 범위로만 쓰고,
  그림에는 모든 조제를 점으로 보인다 (빈 원 = 별도 조제, 총농도 불명).
- DQ–TBZ 는 부호도 조제에 따라 뒤집힌다 (+0.30 → −0.14) — **상쇄 쌍**:
  흡착 우세(DQ)와 분자당 신호 우세(TBZ)가 거의 지워져 환경이 승자를 정한다.
  단일 교차점으로 기술하지 않는다.

추가 실험은 하지 않기로 했으므로(2026-11-09), 이 범위가 이 데이터의 최종 수위다.

## DQ–TBZ 의 자기 이야기 — 등온선 세 가지가 말해주는 것 (2026-11-09)

빼는 쌍이 아니라, "신호 = 흡착 × 단면적" 두 축이 독립임을 보여주는 쌍이다.

1. **단독 K 역설**: TBZ 는 단독 친화도 최대(K = 3.3×10⁴/M)인데 혼합·필름에서
   밀린다. 단독 K 는 깨끗한 표면 기준이고 실제 표면은 CNF 선점 — TBZ 는 CNF 를
   못 밀어낸다(DFT +1.21 eV). 혼합의 승부는 평형 친화도가 아니라 자리 빼앗기다.
2. **DQ Freundlich n ≈ 0.52**: 농도를 올려도 신호는 제곱근으로만 — 누울 자리
   소진 → 세움 전환(DFT −1.82→−1.12 eV). TBZ 50 µM 고정 슬라이스에서 DQ
   150→500 µM 에 f_DQ 0.83→0.26 으로 떨어지는 비단조와 정합하는 메커니즘 후보
   (조제 1장씩이라 후보까지만).
3. **응답곡선의 상쇄 정량**: 성분별 세기 차가 THI 쌍 ~1 dex vs DQ–TBZ ≤0.3 dex
   (부호도 조제 간 뒤집힘). 흡착 우세(DQ)와 분자당 신호 우세(TBZ)가 2배 이내로
   상쇄되는 칼날 — 승자는 조제·건조 동역학이 정하고(글씨 필름의 TBZ 침묵과 같은
   원리), 비재현 자체가 물리의 귀결이다.

**캡션 문구**: "DQ–TBZ, the cancellation pair: adsorption (DQ) and per-molecule
response (TBZ) offset within a factor of ~2, so the winner is set by preparation
and drying dynamics — direct evidence that coverage and cross-section act as
independent axes." (DFT 와 모순 아님 — 두 축의 독립성 증거로 쓸 것.)
