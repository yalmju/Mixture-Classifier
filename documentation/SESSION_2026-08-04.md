## 1. 확정된 것

### 용액 조성 — DL이 이긴다

| 방법 | 전체 34맵 | 삼성분 7맵 |
|---|---|---|
| **MLP (고정 300 epoch)** | **19.1%** | 28.9% |
| NNLS (픽셀 평균) | 27.2% | 43.4% |
| MCR-ALS (6 iter) | 27.3% | 40.8% |
| NNLS (맵 평균) | 28.6% | 45.2% |
| 무입력 상수 대조군 | 54.1% | 34.5% |

- **MCR-ALS는 NNLS 대비 개선이 없다** (27.3 vs 27.2) → 논문에 "NNLS를 썼고 MCR-ALS는 이점이 없었다"
- **삼성분에서는 DL이 무입력 상수보다 나쁘다** → 삼성분 조성 정량 우위는 주장 불가

### epoch 선택기가 고장이었다 — 고정 300으로 교체

`train_model`이 홀드아웃 맵으로 epoch을 고른 뒤 그 값으로 refit했는데, **34맵에서는 그
선택이 성립하지 않는다.** 20% 그룹 분할이 검증 맵 7개만 남기고, 검증 곡선이 하강-상승이
아니라 잡음이다:

| seed | 고른 epoch |
|---|---|
| 0 | 75 |
| 1 | **2** (사실상 사전학습 모델) |
| 2 | 61 |

"최적" 이후에도 계속 진동한다 — seed 1: ep2 0.529 → ep10 1.166 → ep20 0.934 → ep100 0.748.

leave-one-map-out이 선택기의 손해를 확인해준다:

| LOO 설정 | 전체 34맵 | 삼성분 |
|---|---|---|
| **350 epoch** | **19.1%** | **28.9%** |
| 선택된 6 epoch | 22.8% | 39.5% |

→ **논문 수치는 19.1%.** 선택기를 끄고 **고정 300**으로 바꿨다. 맵이 충분해지면 재검토.

### 경쟁흡착 — 삼성분이 가장 강한 증거

| 물질 | 전체 34맵 표면/용액 | **삼성분 7맵** |
|---|---|---|
| THI | 1.69× | **2.33×** |
| TBZ | 0.80× | **0.26×** |
| DQ | 0.50× | **0.41×** |

DQ는 25맵 중 5맵, TBZ는 7맵에서 표면 존재비가 정확히 0.

### 흡착 세기 K (INK 포함 템플릿, 등온선 R² 0.97–0.99)

| 물질 | 반포화 | K 상대 |
|---|---|---|
| DQ (diquat) | 570 µM | 1.0 |
| TBZ (thiabendazole) | 48.9 µM | 11.7 |
| THI (thiram) | 31.7 µM | 18.0 |

K는 곡선이 꺾이는 위치라 기판 gain에 불변. gA(밝기) 비교는 gain과 분리 불가라 사용 금지.

### 활성화 함수 — ReLU 유지 (맵 단위 LOO, 시드 10개)

| | 전체 34맵 | 삼성분 |
|---|---|---|
| identity | 22.1% ± 0.8 | 37.1% |
| **relu** | **20.6% ± 0.6** | 34.3% |
| silu | 20.6% ± 0.6 | 33.1% |
| gelu | 20.8% ± 0.6 | 33.2% |

relu−silu = 0.05%p (시드 산포 0.81%p) → 구별 불가. identity만 1.5%p 나쁨 →
**비선형성은 필요하나 종류는 무관.**

### 농도가 안 되는 이유 (설계)

- 같은 비율을 다른 농도에서 찍은 맵 **0/34** → 비율과 농도가 완전히 얽힘
- 조성이 농도 분산의 **89%**를 설명
- 총 spike 농도가 400–3000 µM, **0.88 dec**만 변함
- 총신호 vs 총농도 **R² 0.02**

## 2. LOD — 확정됨 (세션 말미)

`3.3σ/기울기`, blank = **INK**(종이+잉크), INK 포함 템플릿, 맵 400픽셀 기준:
**DQ 84 nM · TBZ 94 nM · THI 83 nM** (15–20 µg/L). 단일 픽셀이면 1.7–1.9 µM.

세 물질이 거의 같은 것은 σ와 기울기가 함께 커지기 때문 — **검출한계를 정하는 것이
분자 감도가 아니라 기판 잡음**이다. K는 17배 차이나는데 LOD는 차이가 없다.

값이 계속 바뀌었던 원인 셋: blank를 BLK(종이)로 잡음 · readout에서 INK 누락 ·
격자점(onset)을 LOD로 읽음. 도포 순서가 **종이 → 분석물 → 잉크**이므로
"분석물만 빠진 것"은 종이+잉크, 즉 INK 클래스다.

## 2b. 2026-08-05 희석 실험 — 세 가지가 나왔다

1:1:1 혼합액을 1/3씩 연속 희석(333 / 111 / 37 / 12.3 µM), 기판 2세트, 맵당 100 포인트.

### ① 총농도는 잉크 억제가 읽는다 ⭐

```
log10(INK) = −2.01 · log10(C) + 6.32     R² 0.906  (두 기판 공통)
역산: 중앙 1.3배 · 2배 이내 88% · 최악 2.2배
대조: 분석물 NNLS 합 vs 농도 R² 0.350
```

잉크는 같은 픽셀의 **고정량 기준물질**이라 gain이 상쇄된다. 저농도에서 두 기판이 1.05배로
일치한다. **단 잉크가 보이는 구간(~100 µM 이하)에서만** — 34맵은 22맵에서 잉크가 0이다.

물리 정식화(`INK ∝ 1−Σθ`)는 실패(절편에서 K_ink·C_ink = −0.97, 음수). **경험적 log-log만 쓸 것.**

### ② 단일성분 K로 혼합물을 예측할 수 없다

1:1:1 희석이면 경쟁 Langmuir는 표면 조성 **불변**을 예측하는데, 실측은 99.8% → 59%로 변한다.
**응답인자 모델(1:1:29.7)도 같은 이유로 실패** — 둘 다 농도 무관한 일정 조성을 예측한다.
THI/DQ 신호비가 12 µM에서 3, 333 µM에서 500으로 **100배 넘게 변한다.**
→ **농도가 올라갈수록 배제가 심해진다.** 자리 분배가 아니라 밀어내기.

### ③ 모델은 THI만 농도를 따라간다

| | 예측 µM 범위 | 기울기 | R² |
|---|---|---|---|
| THI | 2.97–319 | **+1.38** | **0.88** |
| DQ | 0.018–36.3 | +0.82 | 0.15 |
| TBZ | 1.98–70.2 | −0.17 | 0.03 |

세션 중 ablation이 "농도 헤드가 크기를 안 쓴다"고 했는데, 그건 **34맵에 쓸 크기 정보가
없었던 것**(총농도 0.88 dec)이었다. 1.43 dec가 실제로 움직이는 이 계열에서는 THI가 따라간다.

### 저농도에서도 THI는 검출된다

34맵에서 THI가 용액 1%일 때 표면 10–18% (`TBZ1000THI10` 17.8배 과대).
음성 대조 9맵에서 NNLS 최대 2.3% — 인공물이 아니다.

## 3. 세션 중 뒤집힌 것 — 같은 길로 다시 안 들어가려고

| 한때 주장했던 것 | 실제 | 어떻게 드러났나 |
|---|---|---|
| **반복측정이 없다 (n=1)** | **n=14**가 `calibration_stats.csv`에 있음 | 사용자 지적 |
| blank = BLK(종이) | **blank는 INK.** BLK은 187–293으로 20배 작아 무의미 | 밴드별 잉크 신호 측정 |
| 0.1 µM에서 DQ·TBZ 검출됨 | **잉크였다.** DQ 밴드 잉크 5,920 > 100 nM 표준 3,340 | 사용자 지적 |
| 등온선 R²가 나쁘다 (0.25–0.32) | **readout 문제.** INK 포함 투영으로 0.97/0.99/0.98 | 사용자가 VIP를 알려줌 |
| K 격차 350배 → 8.7배 | INK 포함 정본에서 **18배** | 템플릿 수정 |
| 라벨범위 제약으로 농도 0.37 dec | 그 "검량선 구간"은 **정답 범위**(3.33–500 µM) | 검량선 실측 범위 대조 |
| 고려대 1:1:1이 모델 검증 | 학습 라벨 평균과 같아 무의미 (상수 0% vs 모델 7.5%) | 상수 대조군 계산 |
| SERS ink가 좋은 대조군/내부표준 | 상관 유의하지 않음 (rho −0.30, p 0.086) | 상관 측정 |
| 잉크 소실 = 판독 범위 상한 | 잉크는 증강 매질. 소실 = 분석물이 hot-spot 점유 | 사용자 지적 |
| 삼각형 주장 전체 삭제 | **경쟁흡착 실증은 유지**(최강 증거). 조성 정량 우위만 삭제 | 사용자 지적 |
| 1:1:1 희석에서 표면 조성 불변 | **크게 변한다.** 단일 K도 응답인자도 예측 실패 | 2026-08-05 희석 실험 |
| SERS ink는 쓸모없는 대조군 | **농도 채널이었다** — 1.3배 / 88% | 같은 실험 |
| 농도 헤드가 크기를 아예 못 쓴다 | 34맵에 **쓸 크기 정보가 없었을 뿐.** THI는 따라간다(R² 0.88) | 같은 실험 |
| INK이 조성 MLP의 4번째 분석물 | `is_blank("INK") = True` — **배경 클래스** | 코드 확인 |
| **논문 수치는 22.8%** (배포 설정) | **19.1%.** epoch 선택기가 잡음 최솟값을 집고 있었다 (시드별 75/2/61) | 사용자 지적 → 검증 곡선 확인 |

**공통 원인**: 정본 readout(템플릿에 배경 포함 여부)과 blank의 정의, 데이터 출처를
먼저 고정하지 않고 계산부터 했다. 세 가지 다 세션 말미에 정리됐고 2절에 확정값이 있다.
